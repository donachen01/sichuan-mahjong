# Resource Directory

本目录是工程资源根目录，后续打包时优先从这里检查运行时资源与项目源素材。

## 目录说明

- `art/`: 游戏美术资源，包括图标、麻将牌面、调试牌面。
- `audio/`: 游戏音效与语音资源。
- `ui/`: UI 样式配置等 Godot 资源。
- `source/`: 生成资源所需的源素材，不直接由运行时代码加载。
- `docs/`: 项目规则文档、参考资料等非运行时资料。

## 当前外部资源收拢

- `source/tiles/麻将高清图.jpg`: 麻将牌面生成源图。
- `docs/rules/四川麻将规则.pdf`: 四川麻将规则参考 PDF。
- `docs/rules/四川麻将规则.docx`: 四川麻将规则参考 DOCX。
