# 四川麻将 2.6.82 修复与交付

日期：2026-09-27。基于结构整理提交 `2265c2d`，版本更新为 2.6.82，Android 构建号 342。

## 四项修改

1. **下一局庄家**：新 `scripts/core/dealer_rotation.gd` 依据首批胡牌决定归属。首胡为一人时该人坐庄；只有首批双响/三响共享同一张实体出牌的 ID、来源和胡牌类型时，才由点炮者坐庄。先有单胡、同一人后来再次点炮或出现后续多响，都不能覆盖首胡者。无人胡牌保持原庄；现有首次抢杠多响规则保留。
2. **底部按钮**：关闭与下一局共用原下一局按钮的 Blender 玻璃 PNG、九宫样式和 hover/pressed/focus 状态，文字为白色。使用现有素材，没有重新生成或替换批准美术。
3. **单行道 AI**：`SichuanSingleLaneEvaluator` 替代旧的固定留目标门加分。根据三家定缺、公开出张和剩余活张估计清缺供张；公开证明三家都清缺且没有再次摸牌时，该门未见牌只能位于牌墙。逐个目标摸张后枚举合法弃牌，计入普通胡退路、弃牌风险、可用巡数与封顶收益。保留防守、清缺和尾盘约束；死张、不成形或来不及完成时及时退出。计算只使用公开输入，缓存限定于一次请求。
4. **座位标注**：当前局结算名字旁恢复本家、上家、对家、下家，以本地视角显示，使用工程现有中文字体。

单行道完成率是有限路线模型的估计，采用当前进张率近似后续推进；没有宣称校准后的整局胜率或数学上的全局最大收益。对手隐藏手牌不参与该计算；已出的牌不会被当成未来供张，也不允许吃牌。原有碰/杠/胡反事实决策和危险牌防守继续使用。
