## 结论

2.6.30 已将牌局桌布从偏青、具有明显纵向织带的旧材质，重建为与启动图综合色和细绒方向一致的自然暖绿均衡短绒 PBR。启动图只用于视觉校准，没有提取或复制其像素；最终 BaseColor、Normal、ORM 和 GLB 均由固定种子的 Blender 5.2 脚本原创生成。

四档真实 Metal 成品桌布中位色均为 `RGB(53, 131, 64)`，接近启动图基准约 `RGB(54, 130, 64)`。源贴图、四档成品门禁、确定性重建、八项专项合同、四档空间布局和 C# Release 构建全部通过。

## 改造范围

- `felt_basecolor.png`：自然暖森林绿，保留克制的多尺度明度变化，不生成中心晕染、边缘暗角或大块水渍色斑。
- `felt_normal.png`：四组近等权、多方向高频短绒场，移除旧版单向纵纹。
- `felt_orm.png`：roughness 收敛到 `0.86–0.90`，metallic 为 `0`。
- `sichuan_table_v2.glb`：保留 Blender PBR 材质，法线强度从 `0.52` 收到 `0.34`。
- 限定灯光校准：环境光 `A9B79C / 0.16`，主光 `FFF1E1 / 0.88`；主光方向、阴影参数、牌面专用补光均未改。
- 冻结项：木框、皮革、分区凹槽、中心方向器、镜头、布局、触控、规则、计分、AI、牌体和牌面专用补光。
