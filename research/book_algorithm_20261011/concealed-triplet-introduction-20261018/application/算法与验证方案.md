# 4.2.2 冻结方案 v1

[讨论与用户确认](../人工讨论.md) · [执行结果](./执行结果.md)

修改前全核心源码、DLL和66个分档/17个真实动作的诊断保存在baseline；历史审计只读保留。策略升级v25，不改四川规则及补杠合法性。

## 机制

1. 原表0/1/2暗刻明确索引，个人第8巡进入晚巡；1–2按上限2，重大危险0。普通手的活暗刻先做四副本、合法缺门、提取为杠后完整合法听口不变检查，再保留现有0.10公开获取机会门槛。宽床/两家缺只数听门同门暗刻，既有近清一色、近七对、实际碰后金钩等另立有界发展例外。
2. 宽床歧义行不解除重大危险；1–2张一般危险、两同门活暗刻的“最后1张”按Remaining不含当前来牌解释，无后续有效听张即接胡。无分补杠不算兑现；拒胡历史不因换听、查询或杠兑现而清零。
3. 新摸第三张独立暗刻：枚举全部合法听牌舍牌。比较相同单门、同价格听口的公开墙内分配；不支持的多门、多价格情形保留原引擎。有限墙局部模型只允许一个新暗刻成杠，区分第四张被本家摸得、清缺对手摸到强制供出、他家收走；杠现金由实际规则计，保留根后的胡价、点杠花、杠上花和补牌，计入杠改变轮序及消耗墙牌。整合公开期望墙内听张、第四张的floor/ceil混合，各分支为合法有限墙。
4. 局部模型没有对手提前胡、主动供牌、全部等待失分及终局查叫，不称校准EV。一般或重大危险、在局对手宽床、不可补牌及零第四张不放宽；两家以上缺听门优先宽听。高优先级防守不可被替换。保刻与下一次拒胡完全分开。

## 实现审查修订 v2

首轮运行保留于first_attempt_results.json：57个断言未通过，其中3个是旧碰牌例外误给拒胡额度，54个是新模块调用旧供给估计器时受非公开已听标记影响；88个独立有限墙枚举均通过。60个花色/点数镜像中42个未达到书中偏好，不能当成功。

修正公开分配输入，去掉非公开已听、叫牌和对手过牌合法性矩阵。双暗刻不只逐个检查，还检查同时提取后的完整合法听口，避免替代拆解造成虚假独立。

原先“点估计只要微小较低就不得保刻”的草案超出了未校准模型的证据能力，改为第四张分配敏感性比较：同时计算当前公开分配点估计，以及该未见第四张在墙内的条件值。这不是完整收益置信区间；只检查第四张位置变化是否足以翻转取舍。若能翻转，且已清缺对手的供杠渠道不少于供胡渠道、至少存在一条供杠渠道，或该第四张只有一条顺子使用通道/所有通道受同一仅余一张的邻牌限制，则采用作者保刻偏好。两家缺听门、防守、合法性和无供给约束优先。没有新增固定概率、分差容忍值、牌例特判或乘数。

首打的既有预计放炮失分逐候选扣入局部比较，不用“绝不增加危险度”的额外硬规则阻断所有正常风险取舍；已有重大危险、防守优先级和对手宽床保护仍不可撤销。此处是未校准公开模型加专家序偏好，不宣称终局净收益最优。

末次审查：三家各缺表的≤4张只有正常行，一般危险不借未列明的窄听行放宽；按与5–6张一般危险相同的退出处理，避免越窄反而越贪。两家缺的实际大牌发展另行查找，异门双暗刻不能抢占该发展类型或冒充同门暗刻。

第二轮只有一项失败：异门宽床变体改了定缺后，缺少一家的实际清缺证据；补齐公开证据后，第三轮只剩“几何独立就一定达到0.10获取门槛”的测试前提错误。第三轮保留原始结果，修订为直接核验异门不能进入同门计数，并保留拒胡上限2的独立预期，不对未校准获取点估计伪造精确答案。这两处均不以改生产策略迎合测试。

## 本次聚焦验证范围

这不是固定回归清单。先独立确认分档预期与全部手牌，再比较生产结果。覆盖66个已验证普通手分档及个人第7、8、9巡端点，同门与异门、第四张耗尽、非独立暗刻、无补牌、重大危险、对手宽床及已胡退出、换听和重复查询不刷新；10个原形合成公开补全的摸牌节点及花色迁移。独立小墙枚举检验局部计算的轮序、杠现款、根和补牌，不以生产自己的分数自证。选取相关旧防守与补杠时序验证保护既有认可。

最后重建Godot真实C#，执行108张实体牌的胡、过和舍牌，验证full/compact一致。原书未展示完整对手暗手和牌墙，不冒称原局复刻；不做长期棋力或iPhone已更新的承诺。
