# 补缺实施结论与验收边界

[用户授权、讨论与修订](讨论.md) · [执行结果](执行.md) · [原差距](../reread-20261030/本轮重学总报告.md)。这是本轮研究结论，用户授权实施，不登记为用户已逐条认可。

## 本轮共同能力

1. **逐听价与接胡时机**：同一花色内按实际根价分组，公开观察的信息集决定是否接胡；仅本家摸牌和清缺后的强制供张揭示类别，其他暗摸先边缘化。过胡同价/低价锁、正常摸牌解锁、原共享拒胡次数和安全退出保留。仅处理最多三组且共用强制供张通道的固定手模型，其他背景沿用原声明模型，不能把多组压成平均价再冒充精确拒胡。
2. **真实副本与发展质量**：最多三次实体获取的普通/七对/清色合法目标共同计价。提名使用联合超几何需求，不把多个争同张的搭子事件当成独立概率相乘。清色三步目标与普通/七对两步目标的边界明确；候选目标只是有界政策库，不是全游戏最优解。
3. **连续拆外门和下一次碰**：新观察可改变兼容目标的公开策略图；图在数值墙评估之前生成，实际来张决定相应首打。自适应图覆盖各路线最近目标，较远高价目标另作固定计划计价。普通/七对退路、先后顺序、碰后首打和108实体供给一起约束。
4. **共同动作单位**：碰、过、续打与每种杠后补牌分支用可执行后继的同一有界货币价值。补到定缺牌必须立即打出，其后仍要按共同价值计价，不能让一个分支退回向听加权分数，导致整个开杠比较混用单位。根只在完成牌型中兑现；新增杠现金、退杠等成本单列。
5. **末巡藏牌与价格**：短暗手公开条件下，枚举合法听手并联合分配未知实体，以现有准备度先验作为似然而不是确定事实；重要性校正同时包含实体组合数和各家清缺约束。输出墙内供应及来张相关的他家自摸/放炮价格，避免把对手扣住的高价胡牌当成廉价普通胡。支持不足时明确退出该子模型。
6. **误差和执行**：发现集选政策，独立确认集估值；碰牌小差值与配对采样误差比较。保持原动作时仍保存新的共同价值，不能为了保留原动作又把价值退回旧结构单位。用真实 C# 签发、Godot 实体执行核对，不以 mock 通过代替。

## 不能偷换的验收含义

教材给出的“可以碰”不是所有补充公开背景下都“必须碰”；原书未给完整后墙、对手政策和所有轮序，原例吻合也不是完整收益最优性证明。保留差异及量化原因，不写教材编号条件分支或作者动作标签。

独立计算验证数学与实现；完整自然牌局验证合法执行、结算及本次配对样本表现。两者均不能推出对任意真人的后验已校准、长期棋力必然提高或手机端已经更新。此次没有改动原有本家/左右家手牌 UI，也没有打包、安装或发布。


## 最终验收判断

共同能力的源码、独立数学和桌面执行链已落地，详见[执行结果](执行.md)。这不等于“所有差距已消失”：6-28等仍有作者条件建议与当前模型选择不同的背景；6-26的两种后继虽然碰牌均值转正，却因配对数值误差仍不足而保留过。书中“可碰”已进入真实合法候选及共同估值，不把它强写成所有补充背景的必选动作。

7.1末局已从打1万、听5/8筒改为保留1/4万听；真实桥接条件下打5筒，作者打8筒。二者模型值仅差约0.004，不能据此声称5筒更优，也不能隐去与作者具体弃牌的差异。

后验校准、完整多轮政策最优性和长期棋力提高仍未通过全面验收。64局只是预先声明的自对弈小样本，配对收益区间包含零；没有真人后验校准或手机执行证据。保留这些限制，不把新增代码数量或通过断言数量当作学习已完全内化的证明。
