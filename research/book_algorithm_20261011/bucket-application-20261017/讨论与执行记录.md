# 讨论37：搭子木桶理论（上）算法应用

## 讨论与结论依据

承接[人工讨论及用户原话](../bucket-introduction-20261017/人工讨论.md)。用户明确本节核心为“找出整手成牌的瓶颈；主动组织手牌，补强或替换它”，并要求用于游戏算法。这是本轮实施依据。不是对所有评分权重、书中每一张弃牌和所有后继局面的逐一人工认可。

来源为《技术论（上部）》3.5（上），PDF72—76。3-16是13张观察状态，不捏造成作者给定的14张弃牌；本轮补入的摸牌、定缺、余墙、座位、其他暗手均为受控验证条件。3-17 A—D按原图副露扣实体；D原书只写杠3333筒，测试指定暗杠以明确类型，不声称原书原本就是暗杠。3-18两种损耗条件已重新核对[PDF75](../bucket-introduction-20261017/牌例3-18_原页75.png)及[PDF76](../bucket-introduction-20261017/牌例3-18_原页76.png)。

本轮执行范围：先比较选定普通成牌路线中必须完成的面子块；保留该路线的将，不把将的成刻进张当成必要瓶颈。候补靠牌后，只允许一次实际摸牌和一次实际弃牌，旧弱搭剩余的另一张仍占手牌空间。完成、原块补强、开始替换分别列路径。短板不等于立即拆，供给数量不等于墙内概率或胜率。

`prepare.py`不引用生产算法，独立枚举实体拆分、普通距离、七对距离、公开副本和13张状态的一摸一弃。`independent-results.json`记录44个14张状态；`independent-routes.json`记录24个13张观察根及294条分支。6个根为原例换门/镜像，其余分别耗尽完成张、移去候补、耗尽候补周围供给。每一条分支保存摸牌、弃牌、保留的组、后继普通距离、来牌公开副本数及新的直接完成副本数。

3-16的三条路径可具体检查：7筒直接形成789筒；8/9筒各有3张公开未见，补成889/899后可以保留对子或其他局部结构；6条靠5/7条各有4张公开未见，可形成56/67两面（同样保留4/8条靠坎及6条成对的较弱候补，不只列最有利来牌）。开始替换时只打8/9筒中的一张，不能假定原89筒一次消失。

上述为结构与公开数量证据，不是摸入概率、长期收益最优性或已兑现的杠分。

## 生产改动

- `SichuanFiveBlockPlanner`保持既有成刻保护、少孤张及复合块的选路线前提；在选定路线内明确将牌及必要面子块，不再把将也列入必须成面子的瓶颈排序。记录`HeadTile`、`RequiredBlocks`及实际替换分支。不能在每个候选弃牌后免费搬动将牌来掩盖原短板。
- `SichuanBucketBlockRoutes`分别枚举直接完成、原块补强和候补开始替换。每次摸牌后扣掉已取的一份副本，保留实体互斥，实际弃一张后重新核对整手普通距离。其候补替换结果参与共享五组规划的比较，不只留在笔记中。
- `SichuanCourseTempoPolicy`补上完成张已在手中的排除条件，避免把789里的89误当作未完成弱边搭。该错误在3-16受控摸7筒后真实暴露，旧代码会以`DEPLETED_EDGE_DEVELOPMENT`拆成牌而倒退一步；修正后保留成顺。
- 继续遵守共享入口既有的公开信息完整性、已听牌、清缺、发展时间、安全及战略裁决条件。未改结算规则与自摸加底。

**准确边界：** 路线选择本身与碰牌渠道换算仍有既有启发式（含对子供给的渠道系数、稳定性等级）；新分支的未见副本和结构距离是精算，整个策略排序不是精确概率或全局最优求解。将牌明确是对“选定路线”的角色分配，不宣称穷尽所有路线的长期收益。

## 失败与修订

1. 首次研究程序用了不存在的杠类型枚举名，编译失败；改为项目真实的`ConcealedGang`后重跑，不算算法通过证据。
2. 初版44状态对照有7条“距离差异”：六条3-18原例实际上是普通3上听、七对2上听；另一条为未清缺的距离口径不同。保留`baseline-results.json`的历史失败，修正独立七对计算，未清缺条件只检查合法清缺，不冒充普通路线的比较。
3. 第一次把“去掉将之后”的分数同时用于重新选择父拆分，破坏了3-18既有选择；第二次允许每次弃牌后自由换将，也会隐藏本来要比较的弱块。失败保留于`first-role-repartition-failure.json`、`second-head-switch-failure.json`。修订为先确定当前路线，再在该路线的将不变时比较收缩和发展，其他路线交由原整手战略处理。不是按牌例编号返回固定答案。
4. 3-16直接完成分支发现“已成顺仍拆弱边”错误，按结构条件修复，增加实际后继核验。
