# 讨论52：下部4.4 放飞

[人工讨论](./人工讨论.md) · [执行记录](./执行记录.md)

## 来源与范围

来源：《成都麻将高级》原书第99–106页，对应本项目下部PDF第18–22页，牌例4-21至4-25。本轮只讨论“放飞鸽”：对手打出本家可以胡的牌时，主动选择碰牌，再打出一张牌重新下叫。第五章内容不在本轮范围内。

## 作者观点的结构化转录

- 放飞的基本动作不是单纯Pass，而是“本来可以胡 → 碰掉来牌 → 再打出一张 → 重新下叫”。
- 主要目标是把窄叫变成两头叫、三面叫或更多叫，争取自摸；作者把自摸三家与小胡放炮的收益差作为核心动力。
- 其他放飞目标包括保留或制造带根、对子胡、清一色，及根据对手缺门和牌河进行针对性放飞。
- 放飞有明确风险：放出的牌可能点炮；应优先选择风险较小的花色，并比较改叫后的胡牌空间。
- 这种打法主要适合中局；残局要明显收紧。后续再飞必须有新的牌情和合法碰牌机会，不能凭前一次成功连续乐观外推。

## 已确认并落地的算法

1. 触发条件固定为：对手刚打出一张本家合法可胡的牌，并且碰这张牌合法；没有可胡来牌时不称为本节放飞。
2. 同时建立两条真实动作链：立即胡牌；碰牌后逐个枚举合法首打。碰牌后禁止把“碰后立即补杠”混入本动作，后续补杠另按既定规则处理。
3. 对每个碰后首打，重新计算新听口张数、公开剩余副本、自摸机会、根/番收益、首打危险，以及碰后保留下来的暗刻/碰子在后续正常摸牌中形成暗杠/加杠的机会。
4. 使用独立的连续值比较：`基础续走值 + 宽叫结构收益 + 后续自然杠/自摸路线收益 - 首打危险成本`。自摸和杠是竞争的后续结果，只对较强路线全额计入，另一条只计有限联动项；不把未来杠当成确定收入。
5. 中局允许主动寻找宽叫转换；残局、重大危险、对手睡宽床和高危首打直接保留胡牌。每次新牌情重新判断，不把前次成功当作后续概率。

生产接入点是胡牌反应的统一比较层，生产动作严格输出“碰 + 指定首打”，并在理由中记录重新下叫和未来自然杠机会；不通过普通Pass或虚构未来摸牌替代动作链。

## 尚未冻结的边界

原牌例缺少完整牌墙、对手暗手、事件时序和付款人数，因此专项审计不把作者牌例动作当作隐藏信息下的唯一答案；它验证动作链合法性和生产接入，不宣称作者收益概率已校准。
