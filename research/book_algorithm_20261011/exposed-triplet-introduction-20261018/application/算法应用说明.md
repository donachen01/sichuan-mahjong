# 4.2.1明刻不贪杠：游戏里的决策机制

[来源与牌例](../学习与结构化.md) · [用户认可](../人工讨论.md) · [独立计算及运行结果](./执行记录.md)

问题：碰出刻子后的唯一第四张未到手时，不能仅因将来可能补杠，额外拒胡或把没有真实进展的碰牌后继当作改善。实际取得第四张则转为另一当前合法动作问题。

输入为当前完整自身手牌、公开副露/定缺/弃牌/可见余张、墙量和轮序、拒胡历史及合法胡/碰/杠权限。未知对手牌和未来墙序不进入公平AI。副露中的Peng与手内暗刻分开，暗刻的真实发展价值不受本条一刀切清零。

碰牌计算枚举每个合法碰后弃牌后继，比较上听数及公开供给的变化；已有有依据的整手重建仍按其自身完成机会判断。未来补杠概率只是诊断，不提供独立改善资格、额外拒胡次数、候选加分或弃牌同分优先。已经更好的距离/听口仍可碰，原本有独立理由贪自摸仍可等待。

正式接入为共享`SichuanDevelopmentPolicy`及`SichuanMeldCounterfactualEvaluator`，参与真实反应候选与碰后弃牌排序；胡/过通过`SichuanStrategyContract`及既有公开危险/听张纪律执行。全程使用真实C#；Godot桥接和权威动作执行无需重复实现策略。规则46仍阻止碰后立即补杠，并区分新摸与旧张零现金。

可观察结果：`PENG_FUTURE_ADDED_GANG_NO_GREED`、`EXPOSED_TRIPLET_NO_GREED`；4个虚假改善被消除、52个内部候选分改变，真实供给改善保留。原例不在生产代码中按牌名或编号触发，无新概率/权重。实际杠分、根、抢杠与补牌保留，并有当前动作验证。

原书4-8说明金钩是否贪自摸不由明刻余张单独决定，并不给唯一动作；本轮补全状态选择接胡不表示作者要求所有金钩见胡必胡。该节只关闭明刻未来希望的策略边界，不宣称已解决第五章金钩的全部收益策略。
