## 讨论、授权和冻结范围

用户认可上一轮方案，并强调：“很难的深度算法不是随时触发的，是符合条件才触发，否则游戏体验就很不好了。”本轮授权实现默认快速计算、条件触发深算、保留原深度及统一动作执行。没有授权删除深度，也不要求复制每个书例的开杠动作。

执行前冻结 v1：每个真实座位决策先快速比较；取排名前二的合法候选，继承原反应搜索的 90 策略分接近门槛，且满足以下一种冲突，才可申请一次升级：有效听牌与一向听的速度冲突；两种听牌中一方只有不超过2张活张、另一方更宽；已有高危险证据且具体弃牌风险差异达到0.10；剩余不超过两次本家摸牌的固定轮转预算、涉及杠且存在向听或退杠争议。门槛只是计算预算参数，不能解释为收益等价、置信区间或真实EV。强制动作和已确定的立即动作无需追加竞争搜索。所有假设子状态不得申请升级；升级后不得再重复申请。

默认快速对手查叫预测：至多8个公开假设，具体摸打至多展开一轮活跃座位；剩余墙量继续估值。尾部使用当前有效进张集合、尚未消耗的物理牌墙供应、本家剩余摸牌次数、距离成叫所需进张次数，计算固定集合不放回抽样概率。它不是实战真实成叫概率，不预测后续形状变化、碰杠或退出。原完整32假设逐摸预测及原两阶段模型继续可调用作研究对照；条件深算可调用两阶段恢复听牌模型，普通状态不无条件启用它。血战退出、自摸、杠后恢复、退杠和查叫原有价值项不因缩短具体模拟被直接清零。

碰后立即合法听牌且有活张，在统一策略值相同的候选中优先；不添加任意碰牌常数。明确更高价值的杠不因此被禁止。超出两阶段已覆盖距离的分支不提升成默认两阶段评价，保留既有局部估值并记录限制。

## 本轮聚焦验证范围（非固定清单）

1. 对固定进张尾部概率做独立小规模组合枚举；检查空墙、无进张、供给耗尽及步数不足。
2. 对条件闸门检查普通/明显优劣不升级、速度/薄听/风险/退杠冲突可升级，以及子状态、重复升级、不同座位、请求结束隔离。
3. 用已保存完整公开 own_gang 输入和选定碰杠教材重建情景，检查正式入口、决策理由、条件触发次数、碰后后手与命令一致性。教材重建背景是试验假设，不能声称为历史实际摸牌。
4. 冷进程计时、桌面Godot真实运行时检查；耗时单独执行，不和编译/其他测试并行。新策略可能改变分值或动作，不把旧输出等同于正确答案。

## 最终执行结果

实现文件为 `dotnet/AI.Core/Decision/SichuanSearchBudget.cs`，并接入正式的 `SichuanDecisionEngine`、`SichuanReactionDecisionEngine`、`SichuanSelfActionDecisionEngine` 与 `SichuanMeldCounterfactualEvaluator`。普通入口使用快速具体展开；终局准备度投影只在剩余墙不超过24张或已有对手高准备度证据时启用；深算从候选中只升级一次，候选子状态、搜索叶和其他座位不能重新申请。碰后立即合法听牌只在统一价值相同时作为平局偏好，杠收益、杠后补牌、退杠/查叫与防守约束仍由同一反事实评价负责。命令协议升级为 `unified-seat-policy-v2-adaptive-budget`，Godot 接收校验已同步。

聚焦验证结果：

- 固定进张尾部概率与独立枚举：4,047 项通过；4 个并发座位隔离通过，重复升级和假设分支升级均被拒绝。
- 66 个终局准备度公开状态通过；快速模型固定使用8个粒子，具体对手展开最多一轮，准备度与原完整模型平均绝对差约0.051、最大约0.158。该模型仍标记为简化公开假设，不称为真实胜率。
- 23 个明确背景的碰杠场景通过正式入口；当前策略中 10 个早期版本触发了深算，随后收紧为只有晚墙速度冲突或高威胁/薄听冲突触发，最终 6/23 触发一次，普通快速场景最大约0.89秒，聚焦样本平均约0.79秒，中位数约0.49秒，深算样本约1.57–2.14秒。
- `upper-followup` 5 行、两阶段数学 26 行通过；Godot 真实运行时返回 `GANG_RUNTIME current elapsed=953.964 action=peng`，分数为 pass 106、peng 1001、gang 512，命令协议可被运行时接收。
- Godot/.NET Debug 编译 0 错误；仅有 NuGet 漏洞索引在受限网络下不可访问的 `NU1900` 警告。一次错误脚本路径和一次探针 round 初始化错误已保留在对应失败日志，修正后没有继续失败。

这些是桌面和 Godot 运行时的聚焦证据，不是 iOS/安卓真机性能或完整棋力提升证明；当前未重新打包或安装移动端。
