# 讨论49：破听杠的恢复速度与风险（候选v1）

[学习及作者原例](./学习与结构化.md) · [实际运行与边界](./执行记录.md)

用户在4.2.2应用后回复“继续”。按必要路径进入4.2.3，本轮学习、独立几何复核及现有策略审计；“继续”不等于用户已逐项认可新的破听杠策略或改用书中计分规则。

建议结论：

1. 破听杠可以考虑，但先证明有效再听渠道和时间足够；再听应是有剩余合法胡张的活听，空听不计有效恢复。
2. 三个动作平行比较：过保原听、碰后带根保听、点杠收款后重建。每种补牌和后续舍牌单独计算，保留未听暴露期，而非拿平均向听或单次最大收入排序。
3. 危险和在局对手宽床优先保现成胡牌出口；关键再听牌耗尽、牌墙/个人摸牌机会不足，进一步收紧破听杠。不是“所有破听杠都禁止”，也不是“有4底就必杠”。
4. 全部金额按当前游戏规则、实际在局付款人数重算。作者2底点杠、9底自摸及25%/14%/30%/60%均不直接成为动作常量。退杠、呼叫转移、杠上炮、点杠花应和即时收入一起计。
5. 保留上轮已确认的补杠时机与拒胡纪律；非独立暗刻不参与上一节独立活暗刻额度。没有完整对局校准前，恢复机会是有边界的局部估计，不称真实终局净收益。

本轮先把结果做成可审阅的诊断，新的策略仍为候选。历史4.2.3研究已有分支结构，但收益比较未完成，未晋级的gang_branch_candidate_v1继续保留研究状态，不由此次续学自动变为正式策略。
