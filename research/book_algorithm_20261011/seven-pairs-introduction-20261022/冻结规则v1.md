# 5.4冻结规则v1（2026-10-22）

[用户两条核心反馈及讨论](讨论与结论.md) · [原文及牌面](学习与结构化.md) · [执行记录](执行结果.md)

用户在强调两条主线后要求“继续”，据此进入计算与应用。冻结范围是本节普通七对取舍，不包括下一节新的龙七对结论，不把授权扩为具体阈值或所有原例无条件照做。

1. 比较可兑现收入与代价，不能仅按七对接炮番数排序。普通胡的自摸付款人数、大对子/杠/金钩机会、成叫与成胡速度、途中风险和未叫查叫成本均是比较依据；已收杠钱不重复算作新增收益。
2. 常态在尽量保持普通胡听牌、速度与安全性的条件下兼顾七对。普通与七对向听、有效进张、成叫后的真实叫口及价格按同一合法弃后状态比较。
3. 早盘至少四对、定缺对所需牌有利、普通对子确实难碰三条件同时成立，才开放七对主攻候选；仍须供给、时间、风险及相对收益支持，不由对子数自动推成主攻。
4. 允许有利条件下有限速度投资，并比较保留碰牌转回普通胡的退路；4/6/9巡保留为原例背景，不实现为全局固定巡数开关。
5. 每次新公开信息后可退出七对、保叫或选择合适碰牌。主路线记忆不能先于当前共同比较锁死退路。七对成形或龙七对的真实资格损失仍按规则计算，不粗暴删除所有对子保护。
6. 定缺、公开余张、危险、在局人数与付款者分别从每家自己的视角计算。剩一位普通对手仍有成本；已胡者不参加流局查叫。未知背景显式构造，不据此跳过原例或读取真实对手暗手。
7. 实战与推演复用正式策略，最终动作仍由既有统一入口签发和实体执行；需要的后手随计划传递。额外计算仅在对应形状和可改变取舍时触发。

本次先独立重推四个原例的合法弃后结构与叫口，再对照生产实际入口及执行。计算模型的近似和作者方向差异单列，不以有限测试通过声称长期棋力提高。具体运行范围是本次选取，不成为后续固定回归清单。
