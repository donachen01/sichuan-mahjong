# 2.6.87 仅横屏重力旋转修正

## 反馈与纠偏

用户指出 2.6.86 错误进入竖屏、游戏内不能翻转横屏，并提供竖屏牌桌截图。此前将 Sensor=6 配置与安装启动成功当成旋转修复，证据不足，结论撤回。

Godot 4.6.2 的 SwiftUI 根容器方向传播存在已知问题：[官方 issue 118350](https://github.com/godotengine/godot/issues/118350)。本次恢复 SensorLandscape=4；在 iOS 导出包加入项目原生重力协调器，用 CoreMotion 采样、方向稳定判定与 UIWindowScene 几何请求更新最外层窗口。iPhone/iPad 的 Info.plist 均仅允许 LandscapeLeft/LandscapeRight；竖拿或平放保持横屏。原生处理不依赖 GDScript 场景帧回调。

## 验证

- 原生桥接通过 iOS arm64 API 编译检查。
- 一次性导出验证覆盖 iPhone/iPad 禁止竖屏、原生初始化和 CoreMotion 链接及重复配置不重复插入；通过。
- iOS Release/Apple Development 真机构建成功，检查已签名 app 确认版本 2.6.87、两种横屏、可执行文件含原生采样入口；安装并启动到 dona 成功。
- 真机实时日志中多次传感器请求匹配实际左右横屏；详见 [原始日志](device-orientation.log) 与 [结构化验证](verification.json)。日志记录运行时系统方向，不能替代用户对具体牌桌交互的视觉确认。
- Android 2.6.87 / code347 APK 已生成，v2/v3 签名验证通过，清单仅使用用户横屏传感器方向；未安装 Android 实机。
- 未修改 AI/规则算法，原发布绑定验证通过。本次聚焦检查不形成固定回归清单。

## 验收边界

系统层左右横屏实际切换已获真机日志证明；游戏牌桌视觉表现和竖拿维持横屏等待用户反馈。个人开发者签名继续受 Apple 授权有效期约束。
