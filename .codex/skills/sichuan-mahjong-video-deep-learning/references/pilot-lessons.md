# 首条视频试点复盘

试点视频：`7675206658166918452`，主题“估算手牌，步步为营，转守为攻”。

这次试点确认了五条会改变后续学习质量的原则：

1. 静态牌河不够。`3筒→2筒`与`2筒→3筒`不是同一信息，必须保存逐家动作顺序及手切/摸切来源。
2. 结果不是答案。一筒确实点炮，只能作为新证据更新上家范围，不能反推此前打一筒必然错误。
3. 候选结构必须互相竞争。`23筒听1/4`、一筒作将、大对路线、`667788`等解释要同时列出，再用一副将、绝张和此前不碰行为过滤。
4. 视频通常不给可校准百分比。可以写某结构相对升权/降权，不能从一局虚构“点炮率37%”。
5. “吃透”必须能迁移。相似牌例应复现推理；对手随机、放铳代价变大或有效张减少时，原结论应减弱或翻转。

因此后续不能只做全片OCR摘要。先建立客观时间线，再围绕关键张反复回看，并把每个推理结论绑定原片证据、反例和边界。
