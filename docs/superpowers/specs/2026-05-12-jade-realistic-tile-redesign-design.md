# 青翠实物玉牌轻写实麻将牌设计稿

日期：2026-05-12
项目：内江麻将 Godot UI 牌面重做
分支：`codex/matte-2p5d-tile-redesign`

## 背景

上一轮“温润玉瓷轻立体牌”已经比薄雾面版本更接近麻将牌，但用户进一步反馈了两个核心问题：

1. 整体仍然偏暗，缺少更明亮、更通透的观感。
2. 立体感还不够直接，距离“像高端实物麻将牌”的成品感仍有差距。

因此本次方向进一步收敛，不再追求偏克制、偏柔和的玉瓷气质，而是明确切换为：

`青翠实物玉牌轻写实`

目标是让牌面更接近高端实物麻将牌：更明亮、更直接、更有实体感，但仍保持 Godot 2D 管线下的可落地性。

## 目标

本次牌面重做需要同时满足以下目标：

- 保留现有牌尺寸与主要 UI 布局逻辑，不引发整桌适配重做。
- 牌面整体更明亮，不能再有“偏暗、偏闷”的第一观感。
- 立体感比当前版本更强，但不能回到厚重、廉价、塑料感的旧式页游牌。
- 风格接近高端实物麻将牌，而不是抽象概念风或纯平面设计风。
- 在手牌、弃牌区、副露区、结算页四类场景下都能清楚识别。

## 设计原则

### 1. 实物感优先

这版的核心不是“艺术化表达”，而是“像一块真的高品质麻将牌”。

因此立体感和材质感要更直接地被玩家感知到：

- 顶面必须有清晰但克制的亮面
- 边缘必须有明确但不粗笨的体积关系
- 图案必须在缩小时仍然有高识别度

### 2. 轻写实而不是重写实

不做完全写实照片风，也不追求真实渲染器效果，而是在 2D 资源和轻量运行时阴影内实现：

- 一眼看上去像真实牌
- 细看仍然是干净、统一、适合 UI 的风格

### 3. 可实现性优先

继续沿用现有 Godot 2D 资源与渲染管线：

- 牌体底板通过 PNG 生成
- 牌面符号通过脚本生成与替换
- 运行时只做轻量级边缘、阴影、高亮和状态强调
- 不引入复杂 3D、真材质 shader 或动态灯光系统

## 视觉方案

### 1. 牌体颜色

主牌体采用偏青翠的浅玉绿，不是奶绿，不是暗绿，也不是纯白牌。

具体方向：

- 主体色为浅玉绿
- 顶部受光区更亮、更透
- 中部保持饱满玉感
- 底部略深，形成实物体积

观感应接近高端实物玉牌麻将，而不是彩色主题皮肤。

### 2. 光照关系

采用明确的实物光照关系：

- 左上亮
- 右下暗
- 顶面有连续高光区
- 底边有一条清晰但不厚重的暗边

这套关系要比“温润玉瓷版”更直接，让玩家一眼就能感到牌的体积。

### 3. 厚度处理

不做夸张厚实体侧边，但要明显强于当前版本：

- 保留轻薄厚度
- 顶面和底边要形成明确层次
- 可以出现极轻的侧边暗面
- 禁止出现粗厚块状右边、下边唇角

目标是“实物麻将牌轻厚度”，不是“卡通砖块”。

### 4. 边框

边框不做金边，也不做完全消失。

处理原则：

- 使用略深于主体的玉石边线
- 边线更清楚，帮助牌从桌面背景里立起来
- 边框作用是定义实体边缘，而不是装饰

### 5. 牌背

牌背应比当前更像真实高端麻将背面：

- 使用更深一档的青绿
- 保留压纹或暗纹感
- 允许更明确一点的亮暗层次
- 与正面共享“实物玉牌”的明暗语言

## 图案方案

### 1. 图案总方向

图案继续从纯“轻书法感”往回收，采用：

`工整为主，带少量笔意`

原因：

- 缩小时工整结构更利于识别
- 实物麻将牌本身也更强调规整度
- 这更符合“实物玉牌轻写实”总方向

### 2. 花色要求

- 条子：更深、更实，不再偏细弱
- 筒子：红绿灰对比更清晰，缩小后也要有存在感
- 万牌：笔势克制，字形稳，避免发飘
- 一筒：仍保留朱砂红核心，但要更像高品质实体牌印刷

### 3. 缩小时的优先级

图案生成必须优先为以下场景服务：

1. 中央弃牌区
2. 玩家副露区
3. 结算页小尺寸牌列

判断标准不是“单张大图漂不漂亮”，而是“缩小后是不是仍然像实体麻将牌、是不是还清楚”。

## 状态表现

### 1. 选中态

- 保留朱砂红细边
- 保留 `1.05x` 放大
- 不额外加大氛围光

### 2. 胡牌态

- 与选中态分离
- 使用更柔和的红边或外发光
- 强度低于选中态，不能抢走牌本体的实物感

### 3. 最近打出牌

- 只保留轻量提示
- 不做明显闪烁和浮夸 glow
- 重点是顺序提示，不是视觉主角

## 弃牌区专项修正

用户已经多次指出弃牌区会主观上“显小”，本次必须持续优先关注。

修正逻辑：

1. 先通过牌体更满、图案更实，提升视觉占比
2. 如仍显小，再调中心弃牌默认缩放
3. 保留溢出保护逻辑，避免中间区被挤坏

默认可以允许中心弃牌区较之前略大，只要布局稳定即可。

## 技术实现方案

### 1. 资源层

需要重做或继续替换：

- `res/art/ui_3d_cartoon/tile_face_large.png`
- `res/art/ui_3d_cartoon/tile_face_table.png`
- `res/art/ui_3d_cartoon/tile_back_table.png`
- `res/art/ui_3d_cartoon/tile_symbols/*.png`

### 2. 生成脚本

优先改造已有脚本：

- `tools/generate_cartoon_tile_bodies.py`
- `tools/generate_cartoon_tile_symbols.py`
- `tools/preview_tile_redesign.py`

脚本目标：

- 先把牌体做亮
- 再把体积感做强
- 再把图案做实
- 最后用预览图和桌面截图验证结果

### 3. 运行时渲染

继续调整：

- `scripts/ui/TileVisual2D.gd`
- `scripts/ui/HandCanvas2D.gd`

运行时应只负责轻量收口：

- 顶面高光补充
- 底边暗面补充
- 接触阴影
- 状态边缘强调

不要把立体感过多留给运行时补救，主体仍然要来自资源本身。

## 验证范围

实现后至少验证以下四类场景：

1. 手牌区
2. 中央弃牌区
3. 玩家副露区
4. 结算页展示区

每类场景重点看：

- 是否明显比当前版本更亮
- 是否更像真实实体牌
- 缩小后是否仍然清楚
- 弃牌区是否还会显小

## 风险与边界

### 风险

- 如果亮面做得过头，会显塑料感
- 如果底边暗面太重，会回到厚重旧页游风
- 如果图案仍偏细，会继续让弃牌区主观显小

### 明确不做

- 不做真 3D 模型麻将牌
- 不引入复杂实时 shader
- 不做大规模桌面布局重构
- 不在本轮扩展玩法资源范围

## 推荐实施顺序

1. 提亮牌体整体亮度
2. 强化顶部高光与底边暗面
3. 重做图案占比与颜色对比
4. 更新预览图
5. 验证弃牌区
6. 收口运行时状态表现

## 成功标准

当以下条件同时满足时，可认为这版方向成立：

- 用户明确感受到整体比当前更亮
- 用户明确感受到立体感更强
- 牌面更像高端实物麻将牌
- 弃牌区不再被主观判断为“变小”
- 手、弃、碰杠、结算四类场景风格统一
- 方案仍然处于当前 Godot 2D 管线可稳定维护的范围内
