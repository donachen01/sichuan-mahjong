# V17 Green Soft 3D 落地规格

日期：2026-05-07
基准图：`docs/ui_baseline/mockups/v17_final_template_green_soft_3d_reference.png`

## 目标

以豆包修正版作为新的 V17 视觉基准。保留 V17 的布局、尺寸、区域、牌数量和玩法逻辑，只把表现层改成柔和绿色卡通 3D。

## 关键判断

- 立体感不靠重复描边实现。
- 控件只保留一层干净边缘。
- 质感来自柔和渐变、顶部高光、底部暗边、接触阴影和整体桌面光照。
- 背景必须干净，不允许出现局部脏块、水印块或噪声斑。
- 顶部木质桌沿、左右木质桌沿继续延期，不进入本轮。

## Godot 实现规则

1. 背景使用清爽翡翠绿，中心略亮、边缘略暗，纹理透明度极低。
2. 牌槽与动态区域使用绿色软 3D 面板：浅绿/深绿底色、一层暖金边、单向投影、顶部高光。
3. 中心五块区域改成桌面嵌入式绿色面板，不使用浅色白板。
4. 手牌托盘、顶部牌槽、左右牌槽统一使用同一套软 3D 面板逻辑。
5. 玩家信息卡保持深绿半透明，边框为暖金，头像框用青色高光。
6. 麻将牌保持奶油白牌面、亮绿牌背、圆润角、接触阴影。
7. 禁止双重/三重重复框线；可使用轻微内高光，但不能形成累赘线框感。

## 验收

- 第一眼接近豆包修正版的绿色、柔和、干净、厚实。
- 左右碰杠牌区外没有水印块/脏块。
- 中心区域不再像工程线框图。
- 牌与面板有清楚但不过重的阴影。
- 玩法和交互逻辑不变。
