## 2. 目标视觉与交互合同

### 2.1 视觉方向

主题定义为“川式竞技牌桌”：

- 桌布：深翡翠绿绒布，中心略亮、边缘略暗，有轻微纤维质感但不能形成划痕。
- 桌框：深木色或近黑木色窄框，配一条低饱和黄铜压边，不做赌场霓虹。
- 麻将牌：象牙白牌面、玉绿色侧边、稳定接触阴影；牌纹继续使用现有资源。
- 信息 HUD：深绿半透明底、细黄铜边、紧凑排版；不再使用大面积浮动卡片。
- 强调色：只在定缺、庄、当前行动、胡牌和关键操作上使用；避免整屏同一绿色。
- 万缺：酒红 `#8E2F33`；筒缺：靛蓝 `#315A8C`；条缺：青绿 `#247A68`。
- 字体：玩家名和积分为主要信息，定缺徽章字号不得小于玩家名；普通对局不显示长句说明。

### 2.2 信息层级

1. 自家手牌与可执行动作。
2. 最近弃牌、当前行动方和余牌数。
3. 四家姓名、积分、定缺、庄家、已胡状态。
4. 副露、弃牌历史和胡牌来源。
5. AI 辅助与设置入口。

### 2.3 响应式断点

| 模式 | 代表分辨率 | 布局规则 |
|---|---|---|
| 标准横屏 | `2048x1152`、`1920x1080` | 以 16:9 为基准，四家完整显示 |
| 紧凑横屏 | `1365x768`、`1600x900` | 缩小间距，不缩小关键文字和触控下限 |
| iPhone 超宽 | `2556x1179`、`2796x1290` | 横向扩展桌面，不产生黑柱；控件避开刘海/圆角安全区 |
| Android 超宽 | `2400x1080` | 横向扩展弃牌与牌墙距离，手牌保持底部居中 |

### 2.4 最低尺寸合同

- 玩家姓名：标准模式 `30px`，紧凑模式不低于 `26px`。
- 积分：标准模式 `32px`，紧凑模式不低于 `28px`。
- 定缺徽章文字：标准模式 `32px`，紧凑模式不低于 `28px`。
- 定缺徽章：标准模式不小于 `176x64`，紧凑模式不小于 `148x56`。
- 常用图标按钮视觉尺寸不小于 `68x68`，实际触控矩形不小于 `76x76`。
- 动作按钮：“胡”不小于 `132x132`；“碰/杠/过”不小于 `108x108`。
- 自家牌：保持当前大牌可读性，14 张含摸牌间隔必须完整显示。
- 牌与 HUD、动作按钮、屏幕安全区之间至少保留 `12px` 可见间距。

## 4. 组件接口合同

### 4.1 安全区与尺寸令牌

```gdscript
class_name SichuanTableMetrics
extends RefCounted

const DESIGN_SIZE := Vector2(2048.0, 1152.0)
const COMPACT_HEIGHT := 820.0
const TOUCH_TARGET := Vector2(76.0, 76.0)

static func layout_mode(viewport_size: Vector2) -> StringName:
    return &"compact" if viewport_size.y < COMPACT_HEIGHT else &"standard"

static func content_scale(viewport_size: Vector2) -> float:
    return clampf(viewport_size.y / DESIGN_SIZE.y, 0.82, 1.18)

static func safe_margins(viewport_size: Vector2, safe_rect: Rect2) -> Vector4:
    return Vector4(
        maxf(0.0, safe_rect.position.x),
        maxf(0.0, safe_rect.position.y),
        maxf(0.0, viewport_size.x - safe_rect.end.x),
        maxf(0.0, viewport_size.y - safe_rect.end.y)
    )
```

### 4.2 定缺徽章

```gdscript
class_name DingQueBadge
extends PanelContainer

func configure(suit: String, compact: bool) -> void
func set_revealed(revealed: bool) -> void
func get_suit() -> String
```

`configure()` 只接受 `wan`、`tong`、`tiao`；空字符串隐藏。显示文字固定为“缺万”“缺筒”“缺条”，不得在其他家退化成单字“万/筒/条”。

### 4.3 四家身份 HUD

```gdscript
class_name SeatHUD
extends Control

func configure_seat(seat: int) -> void
func render(player: Dictionary, current_turn_seat: int, reveal_ding_que: bool) -> void
func get_content_rect() -> Rect2
func get_ding_que_badge() -> DingQueBadge
```

`render()` 只读快照，不写回 `player`。庄家和已胡标记与定缺徽章分开；当前行动方使用细黄铜外圈或短时亮度动画，不能靠放大节点导致布局跳动。

### 4.4 弃牌层

```gdscript
class_name TableDiscardLayer
extends Control

func render(players: Array, latest_discard: Dictionary, board_rect: Rect2) -> void
func get_lane_rect(seat: int) -> Rect2
func get_center_reserved_rect() -> Rect2
```

固定网格合同：上/下家每行 7 张，左右家每列 5 张；达到第二行/列后向各自牌墙方向扩展，不侵入中心盘保留区。

### 4.5 动作栏

```gdscript
class_name TableActionBar
extends Control

signal action_selected(action: String)

func render(actions: Array[String], status_text: String) -> void
func hide_actions() -> void
func get_touch_rect(action: String) -> Rect2
```

动作字符串只接受 `hu`、`gang`、`peng`、`pass`；组件不直接调用 `GameState`，由 `MainSceneV2.gd` 连接现有处理函数。
