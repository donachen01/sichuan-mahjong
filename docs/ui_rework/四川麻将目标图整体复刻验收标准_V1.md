# 四川麻将目标图整体复刻验收标准 V1

## 目标

牌桌 UI 达到与目标图**几乎一致的成熟商业风**。不要求单张麻将牌与
目标图逐一对应；要求的是各功能区与各视觉要素在**位置、比例、大小、
风格、颜色**上与目标图接近。

## 原则

- 逐功能区、逐视觉要素做"接近"判定，不做整图逐像素或降采样的数字门槛。
- 判定方为**独立 UI 评审子代理**：全新上下文，不知道本轮改了什么，
  只拿「目标图 + 运行截图 + 本标准」逐维度打分并列差距。

## 评审维度

每项判定：**接近 / 有偏差 / 不符**，并写出具体差距。

### A. 布局区域（位置 + 比例 + 大小 + 风格 + 颜色）

1. 玩家手牌区（本家）
2. 碰杠副露区
3. 胡牌展示区
4. 四家弃牌区
5. 玩家名字 / 头像 HUD 区
6. 中央区（余牌 / 骰子 / 回合指示）
7. 动作按钮区（碰 / 杠 / 胡 / 过）
8. AI 建议条

### B. 牌体

9. 麻将牌形状与大小：长宽比、圆角、厚度、字面占比与目标图接近
   （不要求逐张牌花色一致）

### C. 场景整体

10. 摄像机视角：俯角、透视强度、取景范围与目标图接近
11. 灯光：主光方向、明暗氛围、阴影软硬与目标图接近
12. 桌面风格与纹理：蓝桌配色、桌布材质、桌框 / 嵌线与目标图接近
13. 精细度：材质层次、边缘干净度、整体无廉价感

### D. 配色

14. 整体配色氛围与目标图一致（桌面、牌面、牌背、定缺色、HUD 色）

## 通过门槛

- A–D 全部 14 项判为"接近"。
- 完成度高：无明显缺陷、空洞、错位、廉价感。
- 若任一项为"有偏差"或"不符"，本轮不通过，评审师列出该项的
  具体差距（位置 / 比例 / 颜色 / 风格差在哪），进入下一轮修复。

## 每轮流程

1. 我（开发）改代码。
2. 用户在 Mac 上跑 Godot 出运行截图（我在 Linux 沙盒跑不了 Godot）。
3. 独立评审子代理按本标准逐维度打分、列差距。
4. 未通过则据差距清单继续改；通过则收口。
