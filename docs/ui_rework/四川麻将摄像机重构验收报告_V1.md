# 四川麻将摄像机重构验收报告 V1

> **验收结论已撤销：** 用户将本报告与指定目标图直接对比后，确认正交构图未达到目标图的透视和尺度关系。本文仅保留为历史失败记录，不得作为当前通过证据。

日期：2026-07-18

结论：**通过摄像机阶段质量门禁；尚未进入材质、灯光、环境和动画阶段。**

## 1. 最终方案

- 使用真实 3D 场景与正交 3D 摄像机，不改成 2D 假透视；
- 相机俯角约 56.5°，横向偏移为 0；
- 16:9 使用正交尺寸 9.0，宽屏使用 7.4，中间宽高比线性插值；
- 视线中心后移至桌面 `z=-0.20`，同时为对家和本家保留安全边距；
- 摄像机参数通过运行时视觉合同公开，并由独立测试校验；
- 摄像机验收截图固定使用 14/13/13/13 手牌密度并关闭明牌和 AI 浮层，避免非摄像机状态干扰评审。

第一轮 24° 长焦透视虽然通过自动指标，但独立设计师仅给出 16/25，存在“四向尺度失衡”和“角部遮挡与压边”两个 P1，因此没有进入下一阶段。第二轮改为正交 3D 并重新完成全部验证。
