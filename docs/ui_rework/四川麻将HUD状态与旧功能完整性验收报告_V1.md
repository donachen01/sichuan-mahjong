# 四川麻将 HUD、状态与旧功能完整性验收报告 V1

## 1. 结论

第六阶段 **PASS**。主设计师与独立设计师最终均为 `23/25`，五个单项均不低于 `4/5`，`P0=0`、`P1=0`。第四轮最终候选通过，不把前三轮的失败结论改写成成功。

## 2. 失败—整改闭环

1. 第一轮独立复核 `18/25`：超宽屏本家手牌底部裁切，AI 展开窗遮住中央余牌；两项均为 P1。
2. 第二轮 `20/25`：上述 P1 关闭，但 HUD 身份锚点、AI 文字竞争、点炮来源和组件统一度仍不足。
3. 第三轮 `21/25`：HUD、AI 70% 可读性和“上家 + 箭头”来源表达改善，但证据截图出现“本家已胡 / 上家出牌 / 中央本家出牌中”的互斥状态，仍为 P1。
4. 第四轮最终候选：证据状态注入改为与运行时交互合同一致；胡牌画面为“本家已胡 / 上家出牌 / 中央上家出牌中”，响应与 AI 展开状态的本家 HUD 为“响应”。独立复核 `23/25`，无 P0/P1，正式放行。

## 3. 最终实现

- 定缺仅保留条、筒、万三个 `224×224` 大型圆印；触控、等距、颜色与文字双编码均保持。
- 座位 HUD 扩大并重新分配固定状态槽；“已胡”和当前响应不再压住头像、分数或缺门。本家已胡后仍保留姓名、分数和座位身份，不再把整张 HUD 灰成禁用态。
- 响应胡与自摸均保留“胡/自摸 + 取消”；动作栏只发送原有动作，不在 UI 层伪造胡牌资格。
- 已胡手牌全倒下明牌且不可点击；点炮获胜牌只显示一个来源箭头，并新增“上家/对家/下家/本家”来源文字。
- AI 提示窗背景统一为蓝黑漆面与暗金描边，默认 70% 证据状态正文可读；0%–100% 调节、拖动、展开/收起和推荐按钮仍是独立输入区。
- 工具栏 touch/mouse 双事件去重、明牌稳定节点刷新和 20 次循环合同保持通过。
- 超宽屏本家牌深度单独校准，四档都保留完整牌体、底座与阴影。
