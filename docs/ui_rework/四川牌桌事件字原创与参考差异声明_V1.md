# 四川牌桌事件字原创与参考差异声明 V1

## 作者与制作方式

本轮六类事件字由 Codex 在本地项目中按用户确认的“深翡翠精品牌桌”方向进行参数化分层设计，并由 Blender 5.2 确定性渲染。没有调用付费或生成式图像 API，没有抓取、描摹或复制任何参考游戏资源；最终 PNG 可由仓库脚本从可编辑 `.blend` 源工程完整重建。

## 参考清单

- 用户提供的商业麻将目标图仅用于判断信息层级、手机端可读性与“不遮牌、不遮按钮”的构图原则。
- 本项目既有深翡翠桌布、旧铜镶边、暖象牙牌体与朱砂状态色用于建立内部风格一致性。
- 未使用任何第三方事件字 PNG、SpriteSheet、PSD、Krita 或游戏拆包资源。

## 主动差异

- “碰”采用圆形翡翠印与八向独立光点，不使用参考图的字体、轮廓或粒子排布。
- “杠”采用横向深青玉匾与上下铜金嵌线，不复刻任何牌局特效框。
- “胡”采用朱砂圆印和六枚固定金粒，避免大面积金爆和屏幕震动。
- “自摸”采用象牙签与翡翠双环，和“胡”的朱砂印形成明确语义区分。
- “杠上花”只保留三枚小花瓣并放在字框外沿，确保不遮胡牌张。
- “抢杠胡”用斜切入场线表达锐度，整屏和牌桌摄像机始终不移动。

## 分层导出

可编辑源工程保留文字、底印、外环、嵌线、金粒和花瓣等独立 Blender 对象；导出脚本逐一移动正交相机，输出 `1024×512 RGBA` PNG。运行时仅缩放显示纹理，不修改源图像，也不参与触控或规则状态。
