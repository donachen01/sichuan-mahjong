## 真实迭代记录

本阶段没有把第一张能运行的截图作为成品，共做了五轮校准：

1. 初始基线：牌背色差 `62.69`，绿字/红字对比度 `3.89 / 3.31`，失败；
2. 第一轮：牌面进入范围，但牌背色差 `46.68`，绿字/红字 `5.09 / 3.22`，失败；
3. 发现 PNG 已更新但 Godot `.ctex` 仍是 7 月 6 日旧缓存，强制重导入后红字达到 `5.78`，牌背与绿字仍失败；
4. 牌背反向校准到色差 `4.0`，绿字仍为 `5.85`，失败；
5. 降低树脂侧边明度后干净截图全部通过，但完整牌局红字只有 `5.36`，仍失败；
6. 最终深朱红校准后，完整牌局绿字/红字对比度达到 `7.66 / 6.72`，全部通过。

这保证了验收使用的是完整牌局和最终 Godot 导入产物，而不是挑选容易通过的干净截图。
