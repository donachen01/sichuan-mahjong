# 四川麻将夏日蓝桌材质与桌体验收报告 V1

## 1. 结论

第四阶段 **PASS**。夏日蓝桌的主色、纵向纵深、克制织纹、深色实体桌框和冷灰蓝嵌线均达到本阶段门槛；摄像机、牌组排布和麻将牌视觉没有为本阶段取巧改动。

主设计师评分 `24/25`，独立设计师评分 `23/25`；双方每项均不低于 `4/5`，`P0=0`、`P1=0`。

## 2. 真实迭代记录

本阶段没有把第一次接近目标的结果直接判为通过：

1. 基线桌面由远至近反而变亮，纵深方向错误；
2. 第一次修正方向后，总亮度差只有 `0.0175`，未达到 `0.055`；
3. 第二次把近端压得过暗，近端 RGB 距离为 `32.6`，失败；
4. 第三次近端距离仍为 `22.91`，且上中段亮度差只有 `0.0336`，仍未放行；
5. 第四次才同时通过颜色距离、三段亮度、连续色带和微纹理指标。
