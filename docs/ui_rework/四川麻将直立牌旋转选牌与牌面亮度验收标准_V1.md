## 目标与边界

1. 对家、上家、下家暗手的牌高轴必须垂直桌面，倾角绝对值为 `90°`，不得保留朝桌心或朝外的水平倾斜分量。
2. 选牌状态不得再使用整牌半透明底色；必须使用独立、持续旋转、非菱形的图形，且与摸牌标记能靠形状和颜色双重区分。
3. 选牌与摸牌落在同一张牌时，两种标记必须并列且不重叠；开启 reduced motion 时标记保留可见但停止旋转。
4. 本家手牌正面白度应与桌面弃牌白色一致；2048×1152 Metal 截图中，两区域中性白像素的中位亮度差不得超过 `3/255`。
5. 不修改四川规则、计分、AI 决策、tile id、定缺排序、点击映射及既有 iOS 双输入去重。
