# 四川麻将对手牌姿与点炮展示验收标准 V1

## 目标与边界

本关只修正目标图中能够客观比较的三项：上家/下家暗手的物理站立姿态、对家暗手的物理站立姿态、AI 点炮胡牌后的信息展示。摄像机、牌桌材质、灯光、HUD 尺寸、四川规则和 AI 决策保持冻结。

## 量化门禁

### A. 三家暗手必须像竖立在桌面上的麻将牌

- 三家暗手统一使用高角度牌架，牌面相对桌面的倾角为 `74° ± 2°`；不得复用本家为可读性设置的 `48°` 倾角。首轮 `84°` 试制因左右家过于侧薄、绿背面积不足而判定不通过，不能作为最终基线。
- 每张牌必须出现“竖直绿背 + 可见象牙色顶/厚边 + 桌面接触阴影”三层物理线索；不得呈扇形平铺、扑克牌式斜躺或悬空。
- 左右家整列必须沿桌体边线向远端收敛、向本家前景外扩；不得形成向桌心收拢的倒 V。2556×1179 下整列主轴与水平线夹角绝对值目标 `70°–77°`，左右镜像误差不超过 `3°`。
- 主轴方向必须保留符号校验：以屏幕 Y 增大为前景方向，左家前景半段中心相对远端半段的 `Δx ≤ -2%` 画宽，右家 `Δx ≥ +2%` 画宽；与目标图相应位移的绝对差均不得超过 `1.5%`。只比较绝对夹角不算通过。
- 对家牌列保持水平居中；整列水平偏差不超过 `2°`，相邻牌顶边高度差不超过牌高的 `5%`。

### B. AI 点炮胡牌只展示点炮牌

- 当 `seat > 0`、`has_won=true` 且 `winning_source_seat != seat` 时，该 AI 的普通手牌节点必须为 `0`。
- 胡牌区必须且只能存在 `1` 张正面朝上的 `winning_*` 点炮牌。
- 点炮来源箭头必须且只能存在 `1` 个，并保留赢家座位与来源座位身份。
- AI 自摸与本家胡牌维持现有合同，不得因本修复丢失完整倒牌、触控禁用或来源标记。

### C. 回归与交付

- 新增合同必须通过 20 次连续状态切换，无节点累积、无旧状态残留。
- 1365×768、2048×1152、2400×1080、2556×1179 四档真实 Metal 截图均无黑边、透明洞、HUD/牌列遮挡。
- `Sichuan3DTableStageRunner`、`SichuanHudStateIntegrityRunner`、摄像机四分辨率合同以及全量 Godot Runner 全部通过；C# Release 构建 0 error；`git diff --check` 通过。
- 主设计师与独立设计师都必须逐项给分；牌姿、透视落桌感、AI 点炮展示三项均不得低于 `4/5`，且 P0/P1 为 0，方可重新打包安装。
