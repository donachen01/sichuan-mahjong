## 2. 参考布局与空间做法

1. 相机为固定斜俯视，牌桌从上向下逐渐变大；左右桌边构成清晰梯形，画面下边被本家手牌遮挡。
2. 本家暗手是“立起但向镜头后仰”，不是完全竖直；参考图中牌面高度约为画面高度的 16%–18%，单牌投影宽高比约 0.55–0.62。
3. 13–14 张本家牌占画面宽度约 74%–80%；牌与牌只留 2–4 px 视觉缝，新摸牌与其余手牌额外留一个小间隔。
4. 三家未明手牌同样立起，但牌背朝向桌心/镜头；对家横排，上下家沿桌边竖排，并使用近大远小的透视。
5. 碰、明杠、已胡手牌平放；暗杠才显示背面。副露靠近各自桌边，不与中央弃牌河混排。
6. 中央弃牌按四家分区，同一家牌的方向一致；弃牌比本家手牌小约 35%–45%，确保手牌是第一视觉层级。
7. 最新弃牌使用黄色箭头，已胡点炮牌使用同一方向语言标出来牌座位，不只依赖牌的变色。

## 3. 映射到当前四川麻将的实现约束

- 保留四川规则快照、定缺、血战已胡继续、点炮来源、人类胡/取消和 AI 算法；只替换 3D 表现参数和 UI 样式。
- 本家暗手使用 48° 后仰牌架角；已胡后切换到桌面平放角，点炮牌作为独立牌显示。
- 牌面为中性暖灰白，牌胚和牌背为参考绿；避免之前的高亮黄白泛光。
- 桌面改为蓝色纵向层次，暗纹仅作低对比细节；所有可点击区、快照通路与原生 `Button` 信号不因换肤而更换。
