# 内江麻将 V17 精致卡通 3D UI 重构规范

## 目标

把 2026-05-05 稳定版的基础界面升级为「精致卡通 3D V17 精修版」。本轮只改表现层，不改麻将规则、AI、出牌流程、结算逻辑和存档行为。

## 视觉方向

- 核心气质：暖青蓝/翡翠绿牌桌，奶油白 3D 麻将牌，暖金描边，柔化木质托盘。
- 质感关键词：圆润、厚度、柔光、浮雕、低反差纹理、Q 版但不幼稚。
- 禁止方向：纯扁平绿底、刺眼高饱和色、硬直角、无阴影白板、像调试面板的统计卡。

## 已落地的工程化改动

- `scripts/ui/UIStyleConfig.gd`
  - 全局色板调整为翡翠绿、奶油白、暖金、浅木色。
  - `apply_panel`、`apply_plate_panel`、`apply_button` 增强圆角、描边和阴影。

- `scripts/ui/TileVisual2D.gd`
  - 通用麻将牌从 `86x132` 提升到 `92x140` 基准。
  - 新增右侧和底部侧厚绘制，形成卡通 3D 厚牌观感。
  - 牌面改为暖奶油白，牌背改为亮翡翠绿，阴影加深。

- `scripts/ui/HandCanvas2D.gd`
  - 玩家手牌提升到 `108x162`。
  - 取消旧版顶部裁切式视觉，改为完整露出大牌。
  - 新增手牌侧厚和更强柔影。

- `scripts/ui/PlayerHandViewport.gd`
  - 底部手牌托盘由暗绿色改为奶油浅绿半透明面板。
  - 加强暖金边框和浮雕阴影。

- `scripts/game/MainSceneV2.gd`
  - 牌桌背景、中心弃牌区、牌桌木框、操作按钮、对手信息卡统一到 V17 色彩体系。
  - 弃牌区牌尺寸放大，减少“没改动”的视觉落差。
  - 玩家信息卡改为金边翡翠卡片，头像徽章改为奶油底青蓝边。
  - 操作按钮改为更大的圆角 3D 浮雕按钮。

## 后续精修建议

1. 用真实 3D 卡通头像素材替换当前文字头像。
2. 为中心弃牌区制作 NinePatch 位图资源，进一步替代纯代码 StyleBox。
3. 为启动页和牌桌共用一套木纹、牌面、金边、按钮素材。
4. 打包 APK 后用真机截图对照参考图继续微调比例和明暗。
