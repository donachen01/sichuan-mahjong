# 四川麻将光照、阴影、AO 与后处理验收标准 V1

## 1. 阶段边界

本阶段只调整 3D 世界的环境光、单一投影主光、无影补光、牌体接触阴影、SSAO 和克制后处理。前四阶段已通过的摄像机、牌组锚点、牌体尺寸、字面资源和桌面色阶不得改动；灯光调整后的最终截图还必须重新通过桌面颜色与牌面可读性门槛。

本阶段曾按原 iOS `gl_compatibility` 路径做真实对照，结果桌面整体被抬亮约 25–35 级，目标蓝无法保持；继续以此路径交付会形成明确 P1。项目移动端渲染方法因此升级为 `forward_plus`，以保证桌面色彩、SSAO 和桌面 Metal 证据一致。软边仍以低成本 `shadow_blur` 为主，不启用昂贵的方向光 PCSS；移动端性能必须在第七阶段真机门禁重新证明，不能用桌面画质替代。

## 2. 目标光影提炼

商业参考图的主光从左上射入，麻将牌阴影落向右下；牌根存在明显接触阴影，离开牌根后快速恢复为桌面蓝。顶部绿色牌列在两款产品中承担的几何角色不同（参考图为厚牌墙、当前为较薄立手），不能用同一宽度的牌墙阴影作公平硬门槛，因此只保留为诊断。中央牌区也存在牌尺寸、牌数和覆盖率差异；第六轮若直接强求目标图 `13.9%` 的总深影面积，会把侧家和中心阴影拉成长硬黑块，视觉反而退化。因此最终硬指标使用当前几何下的局部 P5 深度与合理覆盖率，阴影方向和商业质感仍由固定光向合同、四图和双设计师严格复核。

## 3. 硬性量化门槛

### 3.1 光源架构与方向

1. 场景继续只使用 `2` 盏实时灯，其中恰好 `1` 盏投影；不得为每张牌创建灯或阴影灯。
2. 投影主光必须为左上主光，阴影屏幕方向为右下；主光节点必须保留可审计的固定旋转合同。
3. 无影补光只能抬麻将牌暗部，不得制造第二组阴影或照亮桌面；环境光能量限定 `0.22–0.42`。实机第二轮证明同层补光会同时洗亮桌布和阴影，因此最终合同将补光限定到麻将牌专用渲染层，能量为 `1.0–2.2`。
4. 投影主光能量限定 `0.90–1.35`；shadow opacity `0.88–1.0`；shadow blur `1.1–2.2`；bias 与 normal bias 必须显式设置，且不得出现影子脱离牌根或表面痤疮。

### 3.2 接触阴影与恢复

1. 在 1365×768 完整牌局中央 `35%–65% × 30%–65%` 牌区内，蓝色桌面/阴影像素的 P5/中位亮度比必须为 `0.45–0.72`。
2. 亮度低于中央中位值 `72%` 的深阴影覆盖率必须为 `4%–10%`，既要落地，也不能把当前较低牌覆盖率的中心染黑。
3. 中央蓝色阴影像素 P5 亮度必须不低于 `45`，不允许死黑或 AO 黑圈。
4. 阴影必须落在牌的右下侧；最新弃牌、立起暗手和倒下副露均需保持同一方向。顶部立手牌列的接触/恢复数据继续输出作诊断，但不再拿不同几何类型冒充硬门槛。

### 3.3 SSAO 与层次

1. SSAO 必须启用；radius `0.45–1.0`、intensity `0.65–1.25`、power `0.8–1.5`、detail `0.25–0.7`。
2. AO 只强化牌与桌面、牌与牌的接缝；不得形成麻将牌外围黑圈或污染象牙白牌面。
3. 四家暗手、中央弃牌和副露的牌缝必须可辨；1365 下不得出现 AO 抖动、颗粒和摩尔纹。

### 3.4 色彩与后处理回归

1. 第四阶段 `analyze_table_material_reference.py` 必须继续全部通过，不允许光照破坏夏日蓝桌三段目标色和连续梯度。
2. 第三阶段 `analyze_tile_reference.py` 必须继续全部通过：牌面/牌背目标距离与红绿字对比不得退化越线。
3. 只允许 Filmic 或等价克制 tonemap；不启用明显 bloom、彩边、锐化光晕或会污染 2D HUD 的全屏效果。
4. 牌面高光不得过曝成纯白大片；深绿牌背不得变成荧光绿或一团黑。

### 3.5 跨分辨率与移动预算

1. `2556×1179`、`2400×1080`、`2048×1152`、`1365×768` 四档均不得有黑柱、透明洞、阴影断层或边缘漏光。
2. 光源合同仍为 2/1；无逐牌物理、无逐牌灯、无 SSIL/SDFGI/VoxelGI。
3. iOS/移动导出必须明确使用 Forward+，最终 App 的项目设置与 PCK 必须包含该值；第七阶段必须用真机启动、帧率/发热观察验证该画质路径，不能只在桌面 Metal 截图里成立。

## 4. 视觉评分门槛

主设计师与独立设计师分别按 5 项评分：

1. 左上主光与右下阴影方向；
2. 接触阴影、半影和 AO 的实体感；
3. 牌面/牌背高光与材质层次；
4. 桌面蓝色、暗部和后处理的克制程度；
5. 四分辨率稳定性与商业成熟度。

通过条件：双方均 `≥23/25`，每项 `≥4/5`，`P0=0`、`P1=0`，第 3 节全部通过。

阴影方向错误、牌体悬浮、死黑 AO、牌面过曝、只在 Forward+ 有效或破坏前阶段量化指标均为 P1，必须重做；小幅高光偏好可列 P2。
