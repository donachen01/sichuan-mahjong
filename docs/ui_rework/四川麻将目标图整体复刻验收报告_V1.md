## 首轮基线（独立评审师，2026-07-20）

对照对象：`evidence/ui_target_layout_20260719/final_matrix/table_2556x1179.png`

总体：布局骨架已与目标对齐（同一类版式），但商业成熟度约为目标的
55%–60%。差距集中在中央罗盘、桌面/灯光明亮通透感、牌体光泽三块。

### 逐项

1. 手牌区 — 接近（本家可略加高；当前用彩色色条、目标用金箭头指示）
2. 碰杠副露区 — 接近（向牌墙再靠拢、组间留白更匀）
3. 胡牌/理牌提示区 — 有偏差（缺左上"排序图标+提示牌+上箭头"簇）
4. 四家弃牌区 — 接近（对齐成固定行列更整齐）
5. 名字/头像 HUD 区 — 有偏差（当前深灰横条卡；目标为方形头像位，
   本家左下更大、四角固定）※头像内容属版权，只比位置/大小/形状
6. 中央八角罗盘 — 不符（最大缺口：目标为彩色八角风向盘+数码风向字+
   四角红蓝绿金描边+独立余牌牌标；当前仅深色小信息片）
7. 动作/功能按钮区 — 有偏差（缺常驻金色"查听"、聊天气泡；按钮偏扁平）
8. 左上菜单/理牌提示 — 有偏差（仅汉堡按钮，缺提示牌簇）
9. 牌体 — 接近（形状对；牌背绿偏暗，目标更鲜翡翠绿+更强高光）
10. 摄像机视角 — 接近（俯角/透视/取景到位）
11. 灯光 — 有偏差（整体偏暗约一档，缺中央亮光池，阴影偏硬）
12. 桌面纹理 — 有偏差（蓝桌偏暗偏平，缺中央明暗渐变与菱形引导纹）
13. 精细度 — 有偏差（整体发灰发暗，材质层次/边缘光泽偏弱）
14. 配色 — 有偏差（蓝太闷、绿偏哑，需整体提亮提饱和增通透）

### 本轮优先修（按商业感影响排序）

1. 重做中央八角风向罗盘（东南西北+数码风向字+四角描边+独立余牌标）
2. 桌面提亮约一档 + 中央亮光渐变 + 菱形引导纹 + 绒布质感
3. 全局灯光上调 + 中央柔和高光池 + 阴影调软（明亮通透）
4. 牌背绿提亮加饱和至翡翠绿 + 牌顶镜面高光
5. HUD 改紧凑方形头像位（本家左下更大、四角固定）+ 功能钮金色高光样式
   ※头像用自有原创美术，不复刻竞品迪士尼角色
