# 四川麻将手牌亮度、对手正面与侧家内倾验收标准 V1

## 本轮范围

只调整 3D 表现层，不修改规则、AI、牌局快照、触控映射或牌面排序：

1. 本家手牌在本机真实 Metal / Forward+ 画面中保持明亮暖象牙色，暗部不能吞掉牌面符号。
2. 三家暗手保持“桌心一侧为翡翠绿牌背、玩家一侧为暖象牙白正面”的实体双面关系，不能再两面都是绿色。
3. 上家和下家的立牌顶部向桌心轻微内倾；只改变无符号暗手的空间姿态，明牌字面方向合同保持不变。

## 硬门槛

- 本家手牌只允许使用克制的材质亮度下限补偿，不能提高全局曝光或把桌布洗白。
- 对手正面必须是独立实体表面，不能用 HUD 或截图后处理伪造。
- 上家、下家顶部的世界空间水平分量必须指向桌心，且立牌仍处于 72°–76° 的近竖直范围。
- `Sichuan3DTableStageRunner.gd` 必须覆盖：本家亮度标记、对手双面材质、左右侧顶部内倾、隐藏/明牌状态与原有牌局合同。
- 至少生成一张 2048×1152 的真实 Metal / Forward+ 证据图并人工复核。
- 聚焦 Godot Runner、项目解析、Python 工具编译与 `git diff --check` 必须通过；既有退出期资源警告如仍存在要如实记录。

## 结论边界

本轮桌面真实渲染与自动回归不能替代 iPhone 真机完整一局、真实手指触控、长时帧率、发热与耗电验收；没有重新打包和安装时不得声称移动端已交付。
