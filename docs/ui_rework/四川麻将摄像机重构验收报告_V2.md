# 四川麻将摄像机重构验收报告 V2

日期：2026-07-18

结论：**通过摄像机阶段质量门禁；尚未进入材质、灯光、牌体、HUD 或动画阶段。**

## 1. 真实迭代结果

V1 正交摄像机在内部旧标准下曾被判定通过，但与用户指定目标图直接对比后，发现它消除了目标的桌面梯形和近大远小，因此撤销该结论。

V2 迭代共进行八轮目标构图校准。其中一轮因本家牌面被严重裁切而直接否决；一轮仅“距底边”失败；第七轮首次达到 15/15；第八轮改为横向视野锁定，在保持目标宽屏差异通过的同时，修复 16:9 下的边缘拥挤。

## 2. 最终摄像机与构图

- 档位：`commercial_reference_perspective_v2`；
- 投影：真实 3D 透视；
- 位置：`(0, 13, 13)`；
- 看向：`(0, 0, -0.50)`；
- 横向 FOV：`49.5°`；
- 宽高比策略：`KEEP_WIDTH`；

- 本家手牌间距：`0.76`，构图锚点 `(-0.42, 0.25, 3.57)`。

## 5. 双设计师复核

主设计师：**24/25**；认为摄像机几何已达标，不把材质、HUD 和侧家牌模精度冒充为摄像机问题。

独立设计师完全重新评分，未沿用旧正交版结论：

| 维度 | 分数 |
|---|---:|
| 透视和桌面梯形接近度 | 5/5 |
| 四家锚点和近大远小关系 | 4/5 |
| 本家牌面尺寸、位置和可读性 | 5/5 |
| 窄屏安全性与中央空间 | 5/5 |
| 排除材质/HUD 后的目标构图接近度 | 4/5 |
| 总分 | **23/25** |

独立结论：**无 P0，无 P1，通过摄像机阶段质量门禁。**

如实保留的 P2：

1. 2556 图左右家整列比目标图略细、略低；
2. 当前中央留白比目标略大，构图重心稍松；
3. 桌面下缘开口略大，近景梯形张力稍弱。

这三项不伪装为已修复，后续必须在“牌组排布/空间张力”阶段重新设定量化门槛。
