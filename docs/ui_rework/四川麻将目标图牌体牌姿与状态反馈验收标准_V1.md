# 四川麻将目标图牌体、牌姿与状态反馈验收标准 V1

目标参考：用户提供的商业 3D 麻将截图，以及旧版中央“余牌”面板截图。本轮只改表现层和手牌显示顺序，不改规则、AI、计分、响应按钮或 tile id 出牌通路。

## 验收矩阵

| 编号 | 项目 | 量化门槛 | 必须覆盖的状态 |
| --- | --- | --- | --- |
| A1 | Blender 分层牌体 | GLB 外框 `0.42 × 0.18 × 0.58`（Godot X/Y/Z，误差 ≤ `0.01`）；至少包含独立的暖象牙主体和翡翠绿背层；四周倒角 ≥ 4 段；正面印刷区每边保留 `0.025–0.040` 安全边；正面不是纯白，绿背不是灰绿 | 单张亮牌、单张暗牌、平放、站立、明牌模式、暗牌模式 |
| A2 | 牌面层次与材质 | 亮牌面源色在 `#E3DDD3–#F4E9D4` 暖中性范围；象牙主体 roughness `0.32–0.48`；绿背 roughness `0.32–0.46`；金属度 ≤ `0.05`；牌体至少出现“顶面/倒角/侧壁/接触阴影”四级明暗 | 1365×768 与 2048×1152 实际 Metal 渲染 |
| A3 | 上/下家站立牌姿 | 侧家站立倾角绝对值 `74°–78°`；牌列世界坐标沿桌边为直线，横向漂移 ≤ `0.03`；暗牌时可见绿色大背面和象牙窄顶边，不得出现灰色平卡；13 张牌无遮挡、无锯齿排布 | 上家、下家；明牌开/关；10/13 张手牌 |
| A4 | 三家碰杠方向和压缩 | 每家副露与该家弃牌阅读方向一致；上/下家每一组副露沿同一桌边轴排列，同组牌距 `0.46–0.54`；新增组沿桌沿方向缩进为并行列，不得把多组摊成穿入弃牌区的超长单列；1–4 组副露不得与手牌或弃牌区相交 | 碰、明杠、暗杠；四家；1–4 组压力状态 |
| A5 | 摸牌锥形标记 | 摸进牌不再显示整块绿色/黄色底色；只允许 1 个金黄色立体锥形/钻石标记；标记位于目标牌上沿之外，投影不遮挡字面；旋转速度 `90–150°/s`；减少动态开启时停止旋转但保持可见 | 本家 13+1、选牌、AI 推荐/危险标记同时存在 |
| A6 | 中央余牌面板 | 取消东南西北和四角彩色方向字；只保留居中的“余牌”、大数字、底部“X家出牌中”；深青黑底、暗金双线切角；三段文本水平中心误差 ≤ `2 px`；面板不拦截触控 | 标准/紧凑尺寸；四家回合；响应阶段状态文案 |
| A7 | 本家缺门右置 | 定缺完成后，所有缺门牌连续排列在最右侧；非缺门牌仍按条/筒/万、点数、id 稳定排序；摸牌 id、选牌 id、点击返回 id 与真实手牌一致；缺门未选择时保持普通排序 | 缺条/缺筒/缺万；13/14 张；重复牌；摸入缺门牌 |

## 视觉判定门槛

- 牌面与桌布必须保持第一视觉层级；中央面板面积不得超过画面面积的 `3.8%`。
- 人手牌单张牌面在 1365×768 截图中的可读高度不得低于 `118 px`；侧家站立牌的短边不得低于 `19 px`。
- 暗牌模式下，上家/对家/下家不能露出符号；明牌模式下三家符号均朝各自玩家方向旋转 `180°`。
- 牌体不允许以整张颜色遮罩表达“摸进牌”；摸牌、选中、推荐、危险、最新弃牌必须各自保留独立的形状或空间反馈。
- 所有装饰节点 `mouse_filter` 或 3D pick 合同不得扩大到非本家手牌；本家每一张可出手牌必须继续返回原始 tile id。

## 通过规则

1. 对应自动化合同全部通过。
2. 至少捕获暗牌、明牌、摸牌、四家副露压力、三种缺门右置五类真实渲染或状态证据。
3. 每张截图按 A1–A7 逐项复核；任何一项失败均回到该项修正，不进入“完成”状态。
4. 构建或 runner 通过只能作为代码层证据，不能替代实际渲染对比。
