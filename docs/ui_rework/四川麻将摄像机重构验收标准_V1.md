# 四川麻将摄像机重构验收标准 V1

> **已作废：** 2026-07-18 经用户指定目标图逐像素复核，本标准的正交摄像机与目标图的明确梯形透视不符，不再用于验收。当前标准见《四川麻将摄像机重构验收标准 V2》。

> 2026-07-18 第二轮修订：第一轮 24° 长焦透视虽通过自动指标，但独立设计评审仅 16/25，并指出四向尺度失衡和高位俯视两个 P1/P2 问题。第二轮在仍属于“摄像机重构”的范围内，改用正交 3D 摄像机；它不改变模型、布局或玩法，只消除牌桌深度带来的尺度漂移。以下门槛已在第二轮编码前确定。

## 1. 阶段边界

本阶段只重构 3D 牌桌摄像机与屏幕构图，不修改：

- 麻将牌模型、贴图、材质和字色；
- 桌布、桌框、灯光、阴影和后处理；
- 手牌、碰杠牌、弃牌的世界坐标与业务状态；
- 四川麻将规则、AI、触控和 2D HUD 功能。

下一阶段只有在本文件全部硬指标通过、自动验证通过、独立设计师评审通过后才能开始。

## 2. 量化验收矩阵

所有屏幕空间指标都使用最拥挤的正常局面：本家 14 张手牌，其余三家各 13 张手牌；摄像机使用真实运行时参数；麻将牌边界使用 3D 牌面四角投影计算。

必须逐一覆盖以下四种横屏分辨率：

| 编号 | 分辨率 | 代表设备 |
|---|---:|---|
| R1 | 1365 × 768 | 16:9 桌面/小屏基线 |
| R2 | 2048 × 1152 | 16:9 高分辨率基线 |
| R3 | 2400 × 1080 | 20:9 宽屏手机 |
| R4 | 2556 × 1179 | iPhone 宽屏参考 |

### 2.1 摄像机硬指标

| 指标 | 合格范围 | 原因 |
|---|---:|---|
| 投影方式 | 正交 3D | 保留真实 3D 模型、厚度和光影，同时消除四家距离导致的尺度漂移 |
| 正交尺寸 | 宽屏 7.4；16:9 9.0；中间宽高比线性插值 | 窄屏多给左右安全区，宽屏收拢中心主体并匹配商业参考 |
| 俯视角 | 55°–58° | 兼顾牌面阅读和 3D 厚度 |
| 相机横向偏移 | 0 | 保证左右严格对称 |

### 2.2 屏幕构图硬指标

以下指标必须在 R1–R4 四种分辨率中全部通过：

| 指标 | 合格范围 |
|---|---:|
| 本家 14 张手牌总宽 / 屏幕宽 | R1/R2：58%–66%；R3：58%–65%；R4：59%–67% |
| 本家单张牌最大高度 / 屏幕高 | 11%–17% |
| 对家单张牌中位高度 / 本家单张牌中位高度 | 58%–70% |
| 左家同排牌最大高度 / 最小高度 | ≤ 1.03 |
| 右家同排牌最大高度 / 最小高度 | ≤ 1.03 |
| 左右家手牌中心到屏幕中心的镜像误差 | ≤ 屏幕宽 1% |
| 本家牌组左右安全边距 | 各 ≥ 屏幕宽 2% |
| 本家牌组底部安全边距 | ≥ 屏幕高 1.5% |
| 四家手牌投影 | 无裁切、无空矩形、无 NaN |
| 中央点 | 不被任何一家手牌投影覆盖 |

宽度采用分辨率分档，是因为运行时锁定垂直构图：它保证麻将牌字在 16:9、20:9 与 iPhone 宽屏上的高度一致，宽屏设备自然获得更多左右留白。不能用单一宽度百分比同时约束不同宽高比，否则会为了填满宽屏而在 16:9 设备裁切手牌。

### 2.3 交互与回归硬指标

- 本家第一张、中间张、最后一张牌的 3D 投影中心都必须反查到正确 tile id。
- 原 `Sichuan3DTableStageRunner` 全部通过。
- 现有 3D 回退、商业成熟度视觉合同及核心当前测试不得因摄像机重构新增失败。
- 四张验收截图的透明像素、纯黑像素、左黑边、右黑边必须全部为 0。
- 本阶段代码差异不得修改灯光能量、材质颜色、牌面资产和游戏状态逻辑。

## 3. 独立设计师评审门槛

独立设计师只读评审商业参考图、改造前截图和 R1–R4 四张改造后截图，并按以下五项各 1–5 分评分：

1. 透视稳定度；
2. 本家牌面可读性；
3. 四向尺度平衡；
4. 中央空间与无遮挡；
5. 商业参考接近度。

评审通过必须同时满足：

- 每一项评分均不低于 4 分；
- 总分不低于 22/25；
- 不存在 P0（无法使用）或 P1（明显影响核心体验）问题；
- 评审结论明确为“通过摄像机阶段质量门禁”。

如果任意一项不满足，必须回到摄像机阶段修改、重新生成四分辨率截图并重新评审。

## 4. 完成定义

只有以下证据同时存在，摄像机重构才算完成：

1. 四分辨率自动屏幕空间合同全部通过；
2. 摄像机参数合同和交互回归全部通过；
3. 四张真实 Metal 渲染截图像素检查全部通过；
4. 主设计者逐张目视检查通过；
5. 独立设计师达到第 3 节评分门槛；
6. 验收报告记录参数、指标实测值、测试命令、截图路径和独立评审结论。

未满足上述六项时，不进入材质、灯光、环境或动画阶段。
