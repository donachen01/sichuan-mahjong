## 自动合同

`Sichuan3DTableStageRunner.gd` 新增并通过以下检查：

- 本家手牌必须请求局部象牙亮度下限，实体牌身材质必须启用克制的 emission，而不是修改全局灯光。
- 上家、对家、下家暗手都必须同时存在暖象牙玩家面与翡翠桌心面。
- 上家和下家实体牌的上端世界空间水平分量必须指向桌心。
- 原有隐藏/明牌、字面方向、自摸、点炮、副露、弃牌和点击映射合同继续通过。

`SichuanTileVisualQualityRunner.gd` 同步更新为双面暗牌合同：玩家侧验证暖象牙正面，桌心侧验证独立翡翠背层；亮牌仍使用圆润象牙实体表面，不恢复不透明白色内框。
