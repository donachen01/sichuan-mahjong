日期：2026-07-18
前置门禁：摄像机重构 V2 已通过

## 1. 阶段边界

本阶段只允许调整四家暗手、副露、弃牌与胡牌牌组的世界坐标、间距、显示缩放和用于验收的布局量测；冻结以下摄像机合同：

- `commercial_reference_perspective_v2`；
- 位置 `(0, 13, 13)`，看向 `(0, 0, -0.50)`；
- 横向 FOV `49.5°`，`KEEP_WIDTH`；
- 本家和对家的既有主尺度不得为迁就侧家而明显缩小。

本阶段不修改牌体网格、牌面贴图、牌背/桌面颜色、灯光能量、HUD 美术、动画时长、规则、AI、计分和状态机。

## 4. 完整牌局空间合同

- 四家暗手均为站立姿态；碰、杠、弃牌和已胡手牌均为平放姿态；暗杠仅扣住规定牌。
- 不渲染实体未摸牌墙；中央空间只给四家弃牌、低密度余牌和临时操作提示。
- 四家弃牌使用固定起点、固定方向，最多 18 张；任意两家弃牌区不得重叠，弃牌不得压住余牌牌匾。
- 四家副露靠各自边缘；本家副露必须位于本家手牌内侧且不进入本家牌面可点击区。
- 已胡玩家手牌倒下；点炮牌独立留缝，箭头/来源座位状态仍存在。
- 本家 14 张最密场景下，首张、中间张、末张投影点击必须仍命中正确 tile id。

## 5. 多宽高比与可用性

1365×768、2048×1152、2400×1080、2556×1179 四档真实 Metal 截图必须同时满足：

- 无黑边、透明洞、桌面缺失、牌列裁切；
- 四家牌列不与玩家 HUD 重叠；
- 本家牌列不遮挡左上工具栏、动作按钮或中央余牌；
- 16:9 的中心仍保留可放置四家弃牌的连续区域；
- 3D 点击映射、2D 回退、明牌即时切换和旧状态动态刷新合同全部通过。

## 6. 双设计师门禁

主设计师与独立设计师都必须对照目标图、2556×1179 候选图和 1365×768 安全图独立评分：

1. 四家牌列锚点与空间比例；
2. 左右家高度、宽度和纵向张力；
3. 本家第一视觉权重与手机可读性；
4. 中央空间秩序及完整牌局承载力；
5. 多宽高比安全性与目标接近度。

每位总分必须 ≥23/25、每项 ≥4/5、无 P0/P1，并明确写出“通过牌组排布与空间张力阶段质量门禁”。任一条件失败必须留在本阶段重做、重新出四图并重新评分。

## 7. 通过条件

只有以下证据全部存在才允许进入牌体与材质阶段：

1. 预先冻结的本验收标准；
2. `--profile layout` 15/15；
3. 完整牌局布局/姿态/点击合同；
4. 四档 Metal 截图 4/4；

6. 双设计师达到第 6 节门槛；
