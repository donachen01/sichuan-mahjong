# 四川麻将夏日蓝桌材质与桌体验收标准 V1

## 1. 阶段边界

本阶段只验收夏日蓝桌的桌布主色、纵向明暗层次、细微织纹、深色桌沿、金属嵌线和桌体实体感。摄像机、牌组排布、麻将牌材质和字面资源沿用前三阶段已通过版本，不得为桌面取巧而改动。

全局主光、阴影精度、AO 和后处理在下一阶段单独验收；HUD 和动作按钮也不计入本阶段。

## 2. 目标色彩测量

以商业参考图的空桌面蓝色像素分区取样：

| 区域 | 目标中位 RGB |
| --- | --- |
| 远端上部桌面 | `(83, 120, 170)` |
| 中段桌面 | `(74, 100, 151)` |
| 近端下部桌面 | `(70, 88, 139)` |
| 桌外/深色围边 | 约 `(34, 40, 61)` |

阶段开始前的当前桌面为 `(71,108,169) → (74,111,172) → (77,113,173)`，下部反而更亮，纵深关系失败。

## 3. 硬性量化门槛

### 3.1 蓝桌主色与纵向层次

1. 1365×768 完整牌局中，上、中、下三段蓝色中位 RGB 与目标距离分别不大于 `18 / 18 / 20`。
2. 使用相对亮度计算：上段必须比中段高至少 `0.035`，中段必须比下段高至少 `0.018`，上段与下段总差至少 `0.055`。
3. 三段蓝色都必须满足 `B > G > R`；不允许紫蓝、荧光蓝、灰白塑料蓝。
4. 纵向梯度必须连续：相邻 5% 高度带的中位 RGB 跳变不得超过 `18`，不得出现明显色带或硬切线。

### 3.2 桌布质感

1. 桌布 roughness 必须在 `0.78–0.94`，metallic 必须为 `0`。
2. 织纹/压纹仅作为近看细节，目标透明贡献为 `2%–6%`；在 1365 图中不能形成抢眼的大花纹。
3. 空桌面局部必须存在轻微像素变化，但 48×48 空白区单通道标准差不得高于 `8`，防止噪点和摩尔纹。
4. 纹理层不得投射阴影、不得挡住麻将牌、不得侵入触控节点。

### 3.3 桌体与围边

1. 桌体保持真实圆角实体：桌框尺寸约 `14.8 × 9.6 × 0.56`、桌布实体约 `13.9 × 8.7 × 0.34`，桌框倒角不小于 `0.20`。
2. 深色外框必须比上部桌面相对亮度低至少 `0.12`，形成稳定包边，不得与桌布融成一片。
3. 嵌线只做低面积冷灰蓝金属线，metallic `0.25–0.55`，不使用大面积亮金或廉价黄边。
4. 2556×1179、2400×1080、2048×1152、1365×768 四档均不得出现黑柱、透明空洞、桌角破面或桌布露出实体边界。

## 4. 视觉评分门槛

主设计师与独立设计师分别按 5 项评分：

1. 蓝色主调与目标接近；
2. 上亮下暗的桌面纵深；
3. 桌布细腻度与克制纹理；
4. 桌框、嵌线和实体层次；
5. 四分辨率稳定性与商业成熟度。

通过条件：两人均 `≥23/25`，每项 `≥4/5`，`P0=0`、`P1=0`，并且第 3 节全部通过。

纹理偏好、极小色差或后续灯光才能完善的高光可以列为 P2；平板感、色带、塑料感、破面、裁切和桌面抢牌均属于 P1。
