# 四川麻将牌组排布与空间张力验收报告 V1

日期：2026-07-18

结论：**通过牌组排布与空间张力阶段质量门禁；允许进入牌体与字面阶段。**

## 1. 真实迭代

本阶段没有把摄像机门禁的宽松阈值重复当作布局通过证据。初始基线在收紧后的 `--profile layout` 下明确失败：左右家平均宽度、顶部和底部三项不合格。

迭代结果：

1. 第一轮将侧家放大并上移，15/15 虽通过，但宽度距失败边界只有 0.03 个百分点，主动否决“擦线完成”；
2. 第二轮将侧家尺度校准到 `1.44`、平均纵向锚点校准到 `z=-1.22`，三项均接近目标中值；
3. 完整牌局探针发现中央余牌与上下家弃牌争抢、本家副露被手牌遮挡，判定仍不通过；
4. 重排四家弃牌安全环、压缩三行弃牌深度、将本家副露上移，并把左右家副露移到各自上侧内轨；
5. 新增 18 张/家压力布局合同，最终暗手、副露、弃牌、中央保留区和本家点击区无重叠。
