# 四川麻将成熟牌桌 UI 设计规范

## 定位

新版牌桌采用“川式竞技牌桌”方向：克制、清晰、偏成熟麻将 App，不使用后台面板式大卡片，也不使用赌场霓虹、装饰光球或营销页构图。

## 事实与责任边界

- `GameState.gd` 和 C# AI Core 是规则与决策事实来源。
- UI 只读取快照并发出用户动作，不重新计算规则、番型和结算。
- `SichuanTableMetrics.gd` 是尺寸、断点和安全区令牌唯一来源。
- `SichuanTableTheme.gd` 是牌桌色板和 StyleBox 唯一来源。
- 所有新中文控件必须使用 `default_ui_style.tres` 内嵌字体。

## 视觉令牌

- 桌布：深翡翠 `#0A3F31` 到 `#23875F`，中心柔光，边缘暗角。
- 桌框：深木 `#251B18`、中木 `#49352D`。
- 压边：低饱和黄铜 `#C8A85E`。
- 主文字：象牙白 `#FFF9E8`；次文字：暖金灰 `#E8D7AA`。
- 缺万：酒红 `#8E2F33`。
- 缺筒：靛蓝 `#315A8C`。
- 缺条：青绿 `#247A68`。

## 信息层级

1. 自家手牌与当前可执行动作。
2. 最近弃牌、当前行动方、余牌。
3. 四家姓名、积分、定缺、庄家、已胡。
4. 副露、历史弃牌和胡牌来源。
5. AI 辅助、设置和退出。

## 响应式合同

- 标准：`2048x1152`、`1920x1080`。
- 紧凑：`1365x768`、`1600x900`。
- iPhone 超宽：`2556x1179`、`2796x1290`。
- Android 超宽：`2400x1080`。
- 背景始终填满 viewport；交互内容始终位于设备 safe area 内。
- 紧凑模式只压缩间距和装饰，不低于关键字体和触控下限。

## 交互合同

- 定缺按钮显示“缺万/缺筒/缺条”，三种颜色不同。
- 本家选定缺前隐藏其他三家缺门；选择后统一揭示。
- 对局中不显示“下一局”；只在结算完成后显示。
- 所有工具按钮实际触控区域不小于 `76x76`。
- 动作栏不遮挡最后一张手牌；隐藏时不占布局空间。
- AI 辅助默认收起，只显示简洁推荐、原因、风险和策略方向。

## 禁止项

- 不把内江报叫、报杠或两门牌状态带回四川牌桌。
- 不用 UI fallback 掩盖 C# AI 同步失败。
- 不通过缩小关键文字来解决布局问题。
- 不让 hover、动画或动态文字改变固定控件尺寸。
