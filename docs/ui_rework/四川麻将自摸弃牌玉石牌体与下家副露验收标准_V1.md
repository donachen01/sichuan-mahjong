# 四川麻将自摸、弃牌、玉石牌体与下家副露验收标准 V1

参考图：用户 2026-07-22 提供的当前牌局图和商业 3D 麻将目标图。本轮只改表现层，不改胡牌规则、AI、计分或 tile id。

| 编号 | 验收项 | 量化标准 | 覆盖状态 |
| --- | --- | --- | --- |
| B1 | 自摸完整手牌 | 自摸时当前手牌的每个 tile id 各渲染 1 次；所有暗手平放且亮面；不生成 `winning_*` 额外节点；不显示点炮来源箭头；不可继续点击出牌 | 本家、三家 AI；无副露/碰/杠后自摸 |
| B2 | 点炮不回归 | 点炮时原有手牌保留，被点炮牌仅附加 1 张；来源箭头仅 1 个 | 本家和三家 AI |
| B3 | 弃牌换行间距 | 缩放后牌长约 `0.673` 世界单位，行距不小于 `0.72`；第 1/2 行、第 2/3 行投影边界不相交；18 张压力状态不进入中央牌匾或手牌区 | 四家 7/12/18 张弃牌 |
| B4 | 玉石牌体 | 外形仍为 `0.42×0.18×0.58`；主体倒角宽 `0.028–0.036`、至少 8 段，避免相邻牌叠成粗白框；翡翠背层厚 `0.050–0.060`（总厚约 28%–33%）；亮牌不再渲染不透明白色内框平面；象牙体 roughness `0.20–0.30`、clearcoat `0.30–0.48`，弱 SSS `0.03–0.10`；暗牌绿面使用圆角网格而非直角平面 | 近景手牌、平放弃牌、侧家暗牌、明牌 |
| B5 | 下家碰杠方向 | 下家副露长边、字面方向和组内排列轴与下家站立手牌一致；组内 X 漂移 `≤0.03`，Z 步距 `0.48–0.52`；碰、明杠、暗杠全覆盖 | 下家 1–4 组副露 |
| B6 | 座位归属清晰 | 对家副露位于对家手牌与中心之间的上方带，不再落在下家副露带内；下家副露靠近下家手牌轨道 | 对家暗杠 + 下家碰/杠同时出现 |

## 通过规则

1. B1–B6 自动合同全部通过。
2. Blender 重建后必须重跑牌体、3D 牌桌和空间布局回归。
3. 必须生成自摸、18 张弃牌、下家碰杠和牌体近景的实际 Metal Forward+ 证据。
4. 如实保留与目标图在角色、场景、字面美术上的范围外差异，不以“能渲染”冒充“质感通过”。
