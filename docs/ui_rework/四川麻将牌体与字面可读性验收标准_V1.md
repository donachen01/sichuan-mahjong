# 四川麻将牌体与字面可读性验收标准 V1

## 1. 本阶段边界

本阶段只验收麻将牌本身：牌体比例与厚度、牌背颜色和层次、牌面底色、筒条万字形颜色、手机端可读性，以及立起/平放状态下的几何一致性。

桌布材质、全局灯光、HUD 和特效分别留到后续阶段；它们不能被本阶段的通过结论掩盖。

## 2. 目标基准

目标图：`codex-clipboard-1a97c61f-0813-4815-810f-247c350ad32b.png`。

在目标图的手牌和对家牌背区域取样后，固定以下基准：

| 项目 | 目标测量值 |
| --- | --- |
| 牌面中性灰白中位色 | RGB `(233, 232, 235)`，约 `#E9E8EB` |
| 牌背绿色中位色 | RGB `(43, 144, 49)`，约 `#2B9031` |
| 绿色符号中位色 | RGB `(26, 84, 27)` |
| 红色符号中位色 | RGB `(146, 37, 28)` |
| 绿字/牌面对比度 | `7.39:1` |
| 红字/牌面对比度 | `6.87:1` |

当前阶段开始前的真实基线为：牌面 `(236, 239, 247)`、绿色 `(36, 137, 49)`、红色 `(221, 83, 104)`；绿字/红字对比度只有 `3.89:1 / 3.31:1`，明确不通过。

## 3. 硬性量化门槛

任一硬指标失败，本阶段即失败，不得进入下一阶段。

### 3.1 色彩与对比度

1. 1365×768 正常牌局截图中，手牌中性牌面中位色与目标 RGB 欧氏距离不大于 `15`。
2. 正常牌局截图中，对家牌背绿色中位色与目标 RGB 欧氏距离不大于 `22`。
3. 牌面不得使用纯白：实现材质任一通道不得为 `255`，截图中性牌面 90 分位最大通道不得超过 `248`。
4. 绿字/牌面对比度不低于 `6.0:1`，且不低于目标值的 `80%`。
5. 红字/牌面对比度不低于 `5.5:1`，且不低于目标值的 `80%`。
6. 条子主绿必须为深绿，不得偏薄荷青；万子主红必须为深朱红，不得偏粉红。

### 3.2 几何、厚度与状态

1. 牌体必须使用真实圆角长方体网格，所有姿态共享 `0.42 × 0.24 × 0.58` 的同一实体，倒角不小于 `0.03`，至少 3 段；不得为平扣姿态单独压缩厚度。
2. 正面印刷平面必须完整落在牌体内，四周可见边距不小于牌宽的 `7%`，不得越界或出现 Z-fighting。
3. 正面、牌背、牌身必须形成至少 3 个可辨层级；不能把牌表现为一张无厚度贴片。
4. 手牌保持立起，碰杠/弃牌保持平放；四个座位的朝向必须符合各自阅读方向。
5. 暗杠扣牌仍显示牌背；已胡玩家的手牌仍按既有合同倒下，不得因材质重做丢失状态。

### 3.3 手机可读性

1. 1365×768 截图中，本家单张手牌的可见高度不得低于画面高度的 `13%`。
2. 本家牌面符号的有效像素包围盒高度不得低于牌面高度的 `54%`，宽度不得低于牌面宽度的 `42%`；二条等天然窄字形只按高度验收，一筒的圆章构图允许高度不低于 `48%`。
3. 在 1365×768、2048×1152、2400×1080、2556×1179 四档中，牌面不得裁切、重叠或被安全区遮挡。
4. 明牌模式下，上家、对家、下家的筒条万必须能凭字形辨认；不接受只靠颜色猜牌。

### 3.4 渲染稳定性

1. 符号颜色不得被环境灯洗成低对比度粉色/薄荷色；同一符号在不同桌面位置的对比度变化不超过 `15%`。
2. 面材质不得使用高强度自发光；牌身可以使用低强度清漆，但 `metallic ≤ 0.05`。
3. 牌面贴图必须使用带 mipmap 的各向异性过滤，远端明牌不能出现明显闪烁或摩尔纹。

## 4. 证据矩阵

必须保存以下真实 Metal 截图：

- 正常牌局：四个分辨率各 1 张；
- 全员明牌：1365×768 与 2556×1179 各 1 张；
- 已胡/点炮箭头状态：1365×768 至少 1 张；
- 单牌近景或材质合同测试：牌面、牌背、侧边、倒角均可见。

每张截图都要通过黑屏、边缘裁切和有效内容检查。测试桩只能补充局部合同，不能替代真实运行截图。

## 5. 双重设计验收

主设计师与独立设计师分别按以下 5 项打分，每项 5 分，总分 25 分：

1. 牌面/牌背色彩接近目标；
2. 字形尺寸与手机可读性；
3. 厚度、倒角、正侧背层次；
4. 立起/平放/暗杠/胡牌状态一致性；
5. 四分辨率稳定性和整体商业成熟度。

通过条件同时满足：

- 两位设计师都达到 `23/25`；
- 每个分项都不低于 `4/5`；
- `P0 = 0`、`P1 = 0`；
- 第 3 节全部硬指标通过。

P2 可以记录到后续精修，但不得包含可读性、状态丢失、朝向错误、裁切或颜色严重偏离。
