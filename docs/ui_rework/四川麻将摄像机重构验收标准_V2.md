# 四川麻将摄像机重构验收标准 V2

日期：2026-07-18

目标图：`codex-clipboard-1a97c61f-0813-4815-810f-247c350ad32b.png`（2556×1179，宽高比 2.1679）。

## 1. 修订原因与阶段边界

V1 使用正交摄像机，虽然易于让四家牌面尺寸统一，但消除了目标图的“近大远小”和桌面梯形，因此已撤销。V2 以目标图实测值为唯一几何基准。

本阶段允许修改：

- 3D 透视摄像机的位置、看向、FOV 和宽高比策略；
- 为匹配目标构图而调整四家手牌的锚点、间距和视觉缩放；
- 验收截图模式、目标图量测工具、摄像机合同测试和文档。

本阶段不修改：麻将牌模型/贴图/材质、桌布/桌框、灯光后处理、HUD 美术、动画、玩法、AI 和状态机。

## 2. 摄像机参数合同

| 指标 | 必须值/范围 |
|---|---:|
| 投影 | 真实 3D 透视 |
| 摄像机档位 | `commercial_reference_perspective_v2` |
| 横向 FOV | 49.0°–50.0° |
| 宽高比策略 | `KEEP_WIDTH` |
| 摄像机位置 | `(0, 13, 13)` |
| 看向点 | `(0, 0, -0.50)` |
| 俯角 | 43°–45° |
| 左右家镜像误差 | ≤ 屏幕宽 1% |

`KEEP_WIDTH` 用于保持目标图的横向牌桌构图；16:9 设备自动获得更大纵向视野，不得为了追求目标宽屏的大牌面而在窄屏上压住 HUD。

## 4. 多宽高比和交互门槛

必须对 1365×768、2048×1152、2400×1080、2556×1179 生成真实 Metal 截图，并同时满足：

- 4/4 无黑边、透明空洞和未覆盖角落；
- 16:9 下桌面、四家牌列和 HUD 不相互遮挡；
- 中央点不被任何手牌投影覆盖；
- 本家第一张、中间张、最后一张的屏幕投影必须反查到正确 tile id；
- 本家牌的几何外壳只允许最多 2.5% 屏高的目标式贴底，牌面字形不得被裁切；
- `SichuanCameraCompositionRunner.gd` 四宽高比全部通过；
- `Sichuan3DTableStageRunner.gd`、3D 回退和商业视觉合同不得新增失败。

## 5. 双设计师质量门禁

主设计师和独立设计师必须分别对比目标图和最终四分辨率截图，按以下五项各 5 分评分：

1. 透视和桌面梯形接近度；
2. 四家锚点和近大远小关系；
3. 本家牌面尺寸、位置和可读性；
4. 窄屏安全性与中央空间；
5. 排除材质/HUD 后的目标构图接近度。

通过必须同时满足：两位设计师各自总分≥23/25、单项≥4/5、无 P0/P1，且独立设计师明确写出“通过摄像机阶段质量门禁”。未满足时必须重做并重新出图，不得进入材质、灯光或动画阶段。
