# 四川麻将课程“快速原则 / 最大几率”与现有 AI 对齐

## 决策合同

普通进攻和均衡行牌按以下词典序执行：

1. 先执行四川规则合法性：定缺牌存在时只能打定缺房。
2. 对每个合法弃牌，计算弃牌后的最优进听数。
3. 优先选择最低进听数；综合评分、番型权重和局部牌形不得把更慢候选顶到前面。
4. 在最低进听数相同的候选中，计算严格有效牌：摸入后能让进听数继续下降的牌。
5. 每门有效牌按当前实际剩余副本计数，扣除自己持有和所有公开牌；同进听下优先严格活张总数最大者。
6. 进听数和严格活张相同后，才比较净分期望、听口质量、番型路线、牌形、危险度和确定性平手规则。

形式化表示：

`d* = arg min_d (shanten_after(d), -strict_live_ukeire(d), -expected_net(d), danger(d), tile_id(d))`

其中 `strict_live_ukeire` 只计入摸入后使进听数严格下降的牌：

`U(d) = Σ_t remaining(t) · I[shanten(hand-d+t) < shanten(hand-d)]`

在把未知牌视为等概率、无放回抽取时，牌墙剩余 `R` 张、有效牌 `U` 张：

- 下一摸前进一步概率：`P1 = U / R`；
- 自己未来还有 `n` 次摸牌机会时，至少摸中一次的概率：`Pn = 1 - C(R-U,n) / C(R,n)`。

当各候选的 `R` 与剩余摸牌次数相同，最大化 `U` 与最大化上述概率等价。实战中现有 AI 会再用公开信息后验估计有效牌位于牌墙而非对手暗手的比例，但不能读取真实未知牌序。

## 与旧 AI 的比较

旧 AI 已具备：

- 标准型与七对向听计算；
- 逐弃牌严格受入计算；
- 扣除可见张后的活张估计；
- 同向听牌形改良、听口质量、番型、风险和净收益。

旧排序的缺口是：普通模式先按混合 `Score` 排序，进听数与活张只在后级打破平手。因此一个番型或综合估值较高、但进听更慢的候选，理论上可能压过更快候选，与课程反复强调的快速原则不一致。

本次改为：普通进攻/均衡模式把最低进听与严格活张置于混合评分之前。明确追分、弃和、防守或保领先模式仍保留场况例外，因为这些状态的目标不是单纯最快胡牌。

## “同向听改良”的边界

现有 `SameShantenImprovementCount` 是局部邻张启发式，会把摸入后保持同一进听数、但局部连接增加的牌记为改良。它不是严格有效进张，不能与 `LiveUkeire` 混成课程所说的“尽快听牌张数”。

因此：

- `LiveUkeire` 进入速度主排序；
- `SameShantenImprovementCount` 只保留在后级牌形评分；
- 后续若要实现“两巡改良率”，应显式枚举“摸入后最佳弃牌”的第二层状态，而不是用邻张数量冒充概率。

## 同步发现的计分修正

课程定义“无论杠出还是未杠，拥有四张相同牌即带一根”。原 Godot 和 C# 都只统计暗手四张，遗漏已经副露的杠。本次已统一为：

`根数 = 副露杠数 + 暗手四张组数 - 龙七对内置第一组四张`

龙七对内置的第一组四张不重复加根；额外四张组和所有副露杠继续逐根累加。

## 当前验证范围

- 新增独立 C# 合同检查：副露杠的金钩钓应为 `2番 + 1根 = 3番`，自摸时每家支付 `2^3 + 1 = 9`。
- Godot 计分专项覆盖副露杠计根。
- AI 独立合同检查确认普通模式先取最低进听，再取同进听最大严格活张。
- 完整 AI smoke 覆盖既有进攻、防守、追分、尾盘、反应、精确牌型、公开推断和结算路径。

课程习题暂不纳入本阶段验收；待算法合同稳定后再逐题建立牌面夹具。

## 四种经典型的结构层

新增 SichuanClassicPatternEngine，不按原始牌张中“有几种重复牌”直接分类，而是枚举互斥的刻子、顺子、搭子、对子和单张拆分，再从最低进听的最优拆分中读取有效对子数：

- 0个有效对子：1型，全手无对；若原始计数存在对子，则标记为“表面对、最优拆分无对”，作为衍牌证据。
- 1个有效对子：2型，一对三单。
- 2个有效对子：3型，全手两对。
- 3个及以上有效对子：4型，全手三对。

每个弃牌候选都会重新拆分。四型分只在“进听数相同、严格活张相同”之后参与裁决：

- 1型偏好保留无对且至少两个有效未完成搭；
- 2型偏好保留一个有效对子并减少单张；
- 3型、4型偏好落成两个有效对子，并识别“两对靠一张”的两对半结构；
- 刻子和四张杠材仍由原有刻子/杠材保护合同处理，不在经典型层重复加权。

普通进攻模式的完整硬顺序现为：进听数 → 严格活张 → 经典型结构 → 对子/刻子/杠材保留 → 听形 → 综合收益。后三项只能在前两项完全相同时细排，不得以“牌型好看”为由退进听或减少严格活张。

当前四型已经进入运行时诊断与同率裁决，但“吃透”验收仍需要课程原题遮答案验证和独立反例验证；不能仅凭四个人工正例宣布完成。
