# 杠后条件后手、改良机会与正式依据修正

本轮继续落实“边打边看，保留做大方向，同时预留后手牌”。正式 AI 更新为 v18：保留已经算出的补牌后手，说明各分支的真实向听范围。当前动作评分保持原值；新的条件机会策略值仍是研究量。六组能力尚未全部补齐。特殊自摸不胡按用户要求排除，普通合法自摸继续胡。

## 教材思路与实际边界

重新对照下部 6.5.1 的 6-19、6-20 及 5.1、5.4：暗刻可能作将，顺子可能传递有效牌；最弱搭子限制成叫速度。新牌解除将牌或搭子瓶颈、延伸宽听，和只拿一次杠分，是不同的取舍。补杠后仍有做大方向、普通牌退路、多面听改良时，不能把这些机会压成一个平均向听数。反之，改良有限或相同向听下杠分更现实，也不能一律拒绝杠。

原文牌例的概率、收益和供牌条件不是项目通用常数。当前游戏的实际付分人数、番数上限、定缺、血战退出、四张物理限制与摸牌时序必须单独处理。完整弃牌与活动供牌人关系不能用“目标门有几张”替代。教材支持比较改良机会，但不直接提供经过当前规则、对手和牌局分布校准的联合未来概率。

本轮来源沿用 `research/technical_theory_reread_20261003/source-binding.json`，没有改写教材或历史结论。

## 已证实的问题

原算法逐个补牌算完后，把向听数与活张汇总取整，再用这个摘要生成“最快向听”“杠后不拖慢成叫”“杠后仍可下叫”的理由。不同分支会有不同弃牌、听口及做大方向，摘要不能代表每一个后手。代表弃牌的危险值也不能说成所有补牌之后的首打危险。

自然节点 `21920113 / 座位 2 / 暗杠` 的摘要是向听 0，但实际评估分支同时包含向听 0 与 1。自然节点 `21818136 / 座位 0 / 暗杠` 的分支范围是 2～3，旧理由却称“不拖慢成叫”。9 个新真实杠机会中，有 8 个包含不同向听后手，7 个同时有听牌和未听分支。

上一阶段 `21710107 / 座位 1 / 暗杠` 的所有未直接胡牌分支都能听，本轮明确核验了这个事实。它不能被用作“平均误判听牌”的实证。保留这项反证，也保留之前的完整续局。

## 新研究工具实际保留什么

研究工具仅接收行动前提取的公开视图，逐个补牌保留：立即合法胡牌、具体弃牌、普通向听、七对路线是否关闭、逐个合法听口价格、清一色最近成型结构及必需瓶颈牌，以及下一次可能摸牌后的普通/七对退路。每个实际可弃张都在图中，实际摸牌后仍按新公开状态决策。

独立裁判从公开牌数另行枚举分组、胡牌、合法听口、下一摸及弃牌、清一色目标结构，核对定缺与第五张限制。9 个真实机会共核对 1,086 个具体弃牌选项、26,586 个条件进张通道、638 次清一色结构检查；共 138,487 项结构断言通过。这些是条件通道与断言数量，不能当作独立样本。

另用 324 个短墙、固定听口、对手不退出的可穷举小例，核对现有有限机会模型；混合听牌/未听后手可以反证“先平均再非线性计算”等价于“每个分支算完再平均”。这只证明所选模型内部计算的差异，不证明当前牌墙后验或机会价值已校准。

研究量先精确复现 v17 原评分，再对照逐分支尾项。直接胡牌的分支不再假设后续弃牌或查叫。新的尾项仍使用未校准的公开边际估计和有限代理模型，尚无联合未来后验依据。9 个新节点上，这项对照没有改变动作选择，不能称为新策略已通过棋力验证。没有按已经看到的终局赢家拟合权重。

## 已接入正式 AI 的修正

共享副露评估器保留本来已计算的补牌分支。自杠决策把“最快向听”改为明确的加权取整摘要，并报告未直接胡牌分支的向听范围；区分部分听牌、部分成叫变慢、全部所评估后手可听，以及代表弃牌危险。所有说法限定于所评估的公开模型分支，不声称穷尽真实隐藏世界。

生产变更只有共享评估器、自杠依据和两处版本常量。当前评分公式、路线权重、合法动作、胡牌、杠分价格及规则保持原计算。旧研究候选仍未晋级。记录分支只保留必要的内存决策信息，不增加正式对局本地记录或完整终局模拟。

## 本次验证结果与限制

- 64 个新自然采样执行，来自 12 个原始牌局组，提取 9 个合法自杠机会，其中 6 个机会来源组实际有暴露；四个焦点座位重复执行的同一全 current 世界按一个原始牌局组计算。首批两种冻结对手的 32 个执行只遇到一次杠，保留这个低暴露结果。
- 对 9 个机会的全部合法根动作跑了 88 条完整、真实规则续局，均结算、平账，重复控制一致；强制行动前 Native 选择时，事件、轨迹与终分全部复现基线。后续才看到的收益只用于开发复盘。
- v17 缺少正式分支证据的失败保留。v18 在 9 个真实公开根局面上通过共享 Core 检查，并通过真实 Debug Native、真实编译 Release Native；评分与动作逐项相同，分支范围说明真实出现。
- 对 v17 与 v18 做 64 个完整配对执行：4 个新原始牌局组、4 个座位、两种冻结对手、两个版本。每对终分差为 0，6 次自然决策实际使用新增依据；完成、平账及本次时延边界均通过。这是依据修正的正确性应用证据，不是胜率或棋力提升。
- 实际编译桌面 Release 的 Native 入口、记录关闭及研究候选拒绝检查通过；共享 Core 的实时决策与研究终局隔离检查通过。正常 Debug 加载目录在 Release 检查后按文件哈希完整还原。没有新打包、iOS AOT 或真机验收。

初次研究工具编译错误、过早读取尚未完成的输出、Native 测试比较整数/浮点字典时的失败均保留。后者经逐字段独立比较确认评分相同，再统一整数表示修正裁判，没有改动牌例或生产评分。
