# 实战与研究分离及策略交付修正

2026-10-02。四处架构修正已落实，范围为公平AI及研究工具；未安装手机或宣称真机验证。

1. 正式游戏默认不写每盘研究记录。Godot shadow记录默认关闭，C#审计默认关闭且关闭时直接计算、不复制审计快照、不锁写盘路径。生产编译拒绝开启研究记录；桌面Debug研究必须显式开启。每座代理仅研究模式积累候选/手牌/结果轨迹；公开事件、当前计划、待执行建议和权威执行确认仍保留。生产实际运行测试确认没有审计文件和详细研究轨迹，必要计划与动作确认可用。
2. 木桶理论已有公开结构计算，新增同速、风险不增加、活张/统一值不下降、路线不受损的逐项供给优势比较。它不是终局收益估计。120个实际入口状态中1例改变选择，追加的花色迁移验证未通过，失败记录保留；它不能据此晋级。新机制保持bucket_local_candidate_v1研究策略：完整对局尚未证明净收益增益，不能为完成接入而晋级。既有已验证的实战机制继续使用。
3. 弃牌由统一裁决记录建议、优先级、接受/拒绝理由；非法建议拒绝，硬尾盘防守/极端避险高于守叫，守叫高于安全提速，全盘计划高于普通候选值。后续低优先级调整不能覆盖已成立的硬安全决定。优先级是决策组织，不是收益权重。研究日志记录完整裁决过程；实战返回简洁依据。契约升级strategy-contract-v3-priority-local，旧代理检查点不能误配新算法。
4. 冻结旧基线和候选源码/真实运行程序集，采用独立工程、相同初始墙、四座轮换、可碰杠与不主动碰杠两种冻结对手，均从自然开局走真实Godot规则到完整四川结算。新实验机制与正式current分别比较：各32个完整分支，共64个最终版本分支；全部完成、账目守恒、初始世界配对一致。保存逐步真实请求/响应/执行快照完整文件及各局结算时文件前缀哈希。结果没有显示净收益增益；实验机制仅1次自然触发，保持未晋级。

交付清单位于research/strategy-release.json。绑定策略/规则/桥接源码、导出工具、过滤配置与实际验证证据；Release/ExportRelease构建及现有手机导出脚本先校验。缺清单、源码变化、证据变化、试验变体误入正式版本均拒绝交付。打包排除研究/测试/证据/tmp/skill资源。正式运行不做终局模拟，终局模拟保留研究入口。
