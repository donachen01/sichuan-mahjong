# 两次共享改良：2026-10-04 研究结果

已实现首摸后一次共享弃牌、次摸后再一次共享弃牌，再固定合法听口的通用研究算法。它修补了“第一次改良尚未听牌，后续机会被全部计零”的明确漏项。每个可观察历史的所有公开粒子先条件化，再选择统一动作；没有逐个隐藏世界选择最优弃牌，也没有把教材具体摸打顺序做成策略规则。自摸合法胡牌直接结束，不实现特殊自摸不胡。

源码、输入、参数、三种后验种子、时域和实际程序集先冻结。编译独立引用旧研究保存的真实 v18 Core DLL，不引用 Core 项目，不改正式算法版本、发布清单或共享构建目录。程序本轮生成新研究记录，终端游戏记录与终局模拟边界未被本阶段更改。

独立排列裁判通过 196 组双观察小墙分布、35,352 项后续首胡收益。双观察后共享动作的收入为 5，禁止的隐藏世界最优平均为 10，二者明确区分。双前缀支持重复牌，条件残余计数非负、总质量为 W−2。

教材 6-20B 的人工三张小墙中，旧一次改良模型收入为 0，新两次改良模型收入为 27。指定“4条后打6万、7条后打8条”的双观察前缀联合收入为 9；独立手牌分解与排列裁判均通过。这里的三张小墙是明确人工假设，只验证模型漏项；原书未给出的牌河、墙和对家牌没有被重建，27 不是该局实战期望。

原 9 个自然公开开发根与 14 个教材牌形合成环境全部覆盖，使用原三种后验种子，并比较两轮、四轮、剩余墙三种相同墙消耗时域。新模型生成 14,115 个第二层后继图；独立裁判检查 1,584 项最终动作收益、200,052 项第一层候选贡献、1,715,061 项第二层共享最大值。所有图的合法动作范围均核对，策略实际选中的后继图另作 666,637 项独立番型/支付价格核验；未声称对全部未选图的价格独立分解。

每个动作的旧固定听口方案仍可由第二次非胡摸牌原张打出实现，全部新自摸收入均不低于旧模型。最大单项增加为自然根 1.1027、合成根 1.6054；这是约束模型的收入增量，不是棋力增益。

自然根最终隔离选择仍全部不变。合成环境仅 6-20A 的 wall32、剩余墙窗口从杠改为先弃 4万、保留后续改良，三种种子一致且稳定性通过。教材 6-20B 在原两组合成环境仍倾向杠；不能凭人工反例修补就宣称完全解释教材选择，也不能用具体牌张规则强制对齐。

4 个根未通过预先冻结的双前缀 ESS 门槛：自然 1 个、合成 3 个。自然失败根的最小 ESS 为 39.44–46.14；三种合成失败根分别有 93.77、90.26、73.39，低于门槛 96。所有根三种种子赢家一致，但赢家一致不能替代条件样本支持。失败全部保留，未挑种子或降低门槛。

本阶段完整完成研究算法和所选独立验证，仍只作 shadow。概率尚未经独立多来源校准；对家碰杠/胡牌退出、公开证据更新、点炮/抢杠/呼叫转移、两次之后继续改良和后手转向、终局查叫等未纳入。因此估计量是固定活动人数及交换墙模型内的有限窗口自摸收入，杠即时入账单列，不能称为实战净期望、完整对局模拟或棋力晋级。

继续工作应先改善低双前缀支持并补实质机会/成本，再取得自然实际入口的有效分歧；之后才能冻结新的独立完整对局至真实结算比较。这批已看过的开发根、种子和合成环境不会重新标记成留出集。
