# 4.1.1 贪自摸：收入和成本——算法实现与验证

来源：用户提供的《四川麻将技术论（上部）》PDF 第 81—83 页。

本次替换正式“有胡可选时”的估值入口，不改变四川规则、前端玩法或三个独立局内智能体的生命周期。三个智能体各自以本家手牌和公开信息调用同一算法；样本与缓存均为本次请求局部数据。

## 收入和成本如何落入算法

核心比较是两个动作从当前时刻到本局结束的增量积分：

`过胡优势 = E[过胡后终局积分变化] - E[立即胡后终局积分变化]`

立即胡分支也模拟后续牌局，但**2026-10-17用户已确认：已胡玩家不参与流局查叫**，不得额外领取查叫款。原版本曾假设“已经胡牌者可能继续收取流局查叫收入”，该前提现已撤回；历史结果保留，不能作为现行规则的收益证据。不重复扣一次机会成本。讨论和重新执行见[新规则记录](../../research/book_algorithm_20261011/draw-assessment-winners-20261017/讨论与执行记录.md)。

每条路线的分解恒等式：

`净收益 = 胡牌收入 + 杠及呼叫转移净额 + 流局结算净额 - 自己放炮损失 - 被其他玩家胡牌造成的损失`

| 原文机制 | 本次实现 |
|---|---|
| 自摸加底、不同听口的收入 | 每次实际模拟成胡后重新使用统一番型和结算引擎计算，不把全部听张套入当前炮胡番数 |
| 活张与三家定缺 | 从公开牌量、弃牌历史、定缺约束采样完整隐藏分配；未见牌同时分配给对手及已胡者的暗手和牌墙 |
| 剩余摸牌次数 | 按实际座位方向、碰杠、补牌、多人胡后恢复点推演整段剩余牌墙；删除最多四次的估计 |
| 付款人数随别人先胡而下降 | 每次胡后退出活动座位；自摸时读取当时真实活动座位计款 |
| 放弃眼前接胡的固定成本 | 两分支终局净收益直接相减，只计一次 |
| 等待期间被自摸、自己放炮、被杠 | 从各次模拟事件的实际番型和支付关系累计，不再用固定 1.5% 放炮概率与自家番数代替对手损失 |
| 再也没胡成、尾盘成本 | 运行到血战结束或流局，执行真实查叫、花猪；删除尾盘固定增加 45% 胡牌分值的奖励 |
| 顺胡限制 | 明确选择“过”后记录当前番数；自己摸牌前，同番及以下接胡禁止，更高番可胡；普通摸牌和杠补牌均解除 |
| 动态策略调整 | 每次正式反应使用最新状态重新比较，不存一个“以后一直不接胡”的决定 |

碰/杠分支与当前 GameState 保持一致：游戏在显式“过”时新增顺胡锁，碰/杠操作本身不新增锁；模拟也遵守这一现有语义。已有本家锁仍按实际摸牌清除。

原文的“约第 8/12 巡胡”和每巡约 0.1/0.2/0.3 底损失是作者经验统计，没有硬编码为本项目概率。

## 计算流程

1. 校验公开牌量守恒、历史完整性、手牌张数、活动座位、已胡公开分值和本次胡牌合法性。
2. 识别普通接炮、杠上炮或抢杠。杠上炮从公开事件还原当时杠款付款人；已经处理过的同炮胡牌者不能再付款/再胡一次。
3. 抢补杠时，将仍在补杠者手中的已公开第四张预留出来，再采样其余暗手和牌墙；不能把它抽进未来牌墙。
4. 先以 32 个公共先验加行为似然样本，配对计算胡、过，以及实际合法的碰/杠路线。
5. 碰牌后使用正式舍牌算法预测必须打出的牌，再计入该强制舍牌的后果。
6. 若发现过胡路线优于接胡，使用独立种子的 128 个新样本确认。只允许预先选出的挑战动作晋升，避免再从确认批次挑最幸运的动作。
7. 有效样本至少 32，且配对优势超过 `max(0.25, 即时胡分×0.25) + 2.4×配对标准误` 才放弃接胡。这是采样安全余量，不是新的游戏规则，也不代表概率模型已经校准。
8. 公开信息不足、样本不足或优势不明确时，保留运行时已确认合法的胡牌，并返回明确原因，不伪造过胡收益。

诊断输出包含样本数、有效样本数、两路线差值和标准误、各项收入成本、自摸概率、自摸时平均付款人数、实际自己摸牌次数和顺胡阻止接胡次数。

## 共用模拟器的直接相关修正

- 原模拟座位方向为 `+1`，已改为 GameState 的 `-1`。
- 接炮/一炮多响后按实际行牌次序中的最后胡牌者恢复摸牌；抢杠后同样处理。
- 抢杠成功时不收补杠钱、不摸补牌；全过则补杠计款并补牌。
- 杠上炮按实际杠款执行呼叫转移，不重复加上已经发生的杠钱。
- 本项目冻结规则是杠钱即时结算、流局不退税；没有移植其他地方规则的退税。
- 对手私有听牌标记、摸牌牌面、过胡矩阵、顺胡锁和过牌合法动作不进入公开推断。保留本家自己的规则锁。

## 验证证据与边界

本轮测试及运行结果见 `evidence/hu_income_cost_20260930/verification.md`。确定牌墙测试使用四张守恒的牌局构造；生产入口测试不接收该确定牌墙，只接收公开状态。

原文三面听案例的合成公开局面中，正式 128 样本确认得到过胡相对接胡的平均优势约 1.974 分，配对标准误约 0.256，自摸时平均约 2.82 家付款。本局选择“过”。这只是附带状态和固定种子下的结果，不代表任何三面听都应该过胡。

机制已进入正式反应决策，但估值仍是有限样本、有限行为模型的概率估计。后续模拟以结构化舍牌、推进上听的碰杠和首个合法胡牌为行为模型，不是递归调用所有智能体完整策略的无限搜索；每到真实新决策会重新计算。尚未完成大规模收益校准、胜率对照或 iPhone 性能测试，不能宣称全局最优或保证胜率提高。
