# 已胡清缺修正与两次改良验收（2026-10-04）

正式策略已推进到 v19：当前四川规则要求清完定缺才能胡牌，公开宣布已胡的玩家，其未知暗牌不得再含定缺花色。已胡玩家仍然持有这些牌，不能把它们退回牌墙。此轮只修正公开事实的合法支持集；新改良评分仍在研究端。

## 正式修正与实际验证

旧版本在两个已见真实局面中，分给已胡玩家定缺牌的后验质量分别约为 99.7% 和 98.4%–99.1%。问题是漏掉清缺约束，并非牌总数不守恒。修正只作用于正式公开粒子推断，保留全部暗手数量、原有重要性权重、活动玩家摸打边界和 legacy 提议算法。

独立小先验裁判通过 384 个案例、8,496 个联合世界；真实公开输入检查了 112,752 个粒子，全部保留正确暗手槽、逐牌守恒，已胡玩家定缺牌数量为零。检查同时覆盖游戏实际使用的 32/48 粒子预算和研究 4,096 粒子预算。这证明合法性，不等于概率已校准。

真实 Native 入口的 9 个局面，均以最新公开视图重新创建四个 Agent，没有改写旧检查点。7 个无人已胡的局面动作和评分精确不变；2 个存在已胡玩家的局面，评分发生变化，最终仍选择杠。正式 Release 的同样入口也通过，并与当前 Debug 动作、评分一致。

两种冻结对手共完成 64 次从开局到四川结算的合法对局，属于 4 个原始种子组，形成 32 个版本配对。3,850 次含终局的逐步实牌检查全部通过，完整记录及结算前缀无损校验通过，所有配对净分差均为零。最大每局决策 P95 为 162 毫秒，仅是本机桌面证据。142 次“其他玩家已胡”的公开请求是使用机会，不能称为动作改变或棋力提升。

第一次研究工具运行把座位 0 误读为 1，被严格座位校验拒绝；失败原始证据保留。修复工具后，已观察的原始种子退出留出组，新四组重新冻结，未按结算分数选择样本。

## 研究评分的实际进展

新模型在实际看到第一次摸牌后统一选择一次弃牌，再在实际看到第二次摸牌后统一选择下一次弃牌；各隐藏假设共享同一个观察历史下的动作，不允许逐世界偷选最优。旧的原张打出、固定听口方案仍被包含，普通合法自摸立即胡牌。用户暂缓的特殊“自摸不胡”没有加入。

独立审计覆盖 23 个开发根、176 个根动作、22,228 条精确父子链接、14,115 个第二层图、1,846,524 个第二层合法弃牌后的番型支付价格、1,584 项同窗口旧/新收入；16 类故意篡改均被拒绝。原验证器漏掉完整候选和父子关系覆盖的不足，已通过追加裁判补上，旧报告保留并附修订说明。

教材 6-20B 的明确人工三张小墙中，原模型漏计的两次合法改良路线已恢复，约束模型的自摸收入从 0 到 27。它证明遗漏，不能当作原书真实牌墙、预测或固定出牌规则。

另一项需纠正的旧文字是 6-20A 人工 wall32 的剩余墙窗口：实际变化为旧弃 6条、新弃 4万，三种粒子种子一致；不是从杠改为弃牌。较短两轮、四轮窗口仍补杠 3条。9 个已见自然根的最终选择仍不变。

四个场景未通过原先冻结的双观察有效样本量门槛：自然 seed21920113、座位2、墙12；人工 6-19A/B/D、墙16。诊断指向重要性权重集中，不能删掉权重或复制粒子制造通过。独立审计完成不等于稳定性、校准或棋力已通过。

该模型目前计有限窗口内自摸收入和单列杠钱；仍缺对家供牌与胡牌退出、不断变化的公开证据、点炮/抢杠/转杠损失、更多次改良与后手价值、查叫等终局影响。因此不能称为完整实战净收益，不进入正式评分。

## 使用边界与接续

正式构建已验证实时决策拒绝真实终局模拟、不能启用研究记录或实验策略，必要的内存策略计划正常保留。终端用户使用时不做每手终局模拟、不落地每盘研究记录。此轮没有新打包、iOS NativeAOT、安装或真机证据。

六组能力仍未全部完成应用。接续应先冻结通用的采样改良或真正新增粒子实验，保持精确重要性校正和原失败记录；然后补齐对手反应、退出、损失与终局收益，取得独立多来源概率校准和真实入口的有依据分歧，再执行完整策略对局晋级。不能依靠放宽门槛、等化权重或照搬教材牌序追认。
