# 两次改良研究的独立验收修订

本修订补齐此前裁判漏验的范围，并纠正一处结果解释。冻结的研究算法、参数、公开输入、种子、输出及旧报告全部保留。新增验收不是新的自然样本，也不表示该评分已接入正式游戏。

原 `verify.py` 核对了合法第二层范围和选中图的番型价格，但未独立证明完整根动作、全部首摸候选、父子链接和旧一次改良收入。后加的第二版裁判补了链接与观察记录，却仍依赖旧根图的完整性。新版第四版独立裁判直接从公开手牌和规则导出根动作，再核对两层每个合法摸牌、弃牌和听口价格，包括所有未选图；每个可观察历史先汇总同一后验，再重算选中动作与全部并列动作。

9 个旧自然开发根和 14 个旧人工教材环境全部通过新增验收，共检查 176 个根动作、22,228 条精确父子转换、14,115 个第二层图、1,846,524 个第二层合法弃牌后的价格、200,052 项第一层候选贡献、641,912 项选中第二层记录，以及 1,584 项同窗口旧一次改良收入和新最终收入。16 类刻意破坏——缺根动作、缺首摸/次摸或弃牌、错父子手牌/残余供给、伪造胡牌终止、错误共享动作、篡改旧收入等——均被拒绝。冻结源码、程序集、输入和旧证据的 150 项绑定复核无变化。

第三版裁判最初错误假定自然根均已清自己的缺，实际第一个公开输入立即否定这个前提。该失败代码、冻结记录与日志已保留。第四版修正为：有缺牌时弃牌必须先打缺牌，非缺牌杠仍可成为候选，合法自摸胡须清缺。修改的是裁判前提，没有改待测算法或追认失败的模型结果。

需要明确纠正旧说明“6-20A 从杠改为弃4万”的文字。相同 wall32、剩余墙窗口下，旧一次改良已经选择弃 **6条（tile5）**，新两次改良选择弃 **4万（tile21）**，三种种子一致。两轮及四轮窗口均仍选择补杠 **3条（tile2）**。

| 后验种子 | 剩余墙：旧最佳动作/收入 | 剩余墙：新最佳动作/收入 |
| --- | --- | --- |
| 90103 | 弃6条 / 3.739353 | 弃4万 / 4.182235 |
| 91112 | 弃6条 / 3.707328 | 弃4万 / 4.218883 |
| 92121 | 弃6条 / 3.693198 | 弃4万 / 4.190604 |

这些数字是同一交换墙假设、固定活动人数、至多两次共享弃牌后的有限自摸收入，并加单列的即时杠钱；不是实战净期望。弃4万保留条子牌形和成对6条，在下一次真实观察后仍可继续调整，比第一次尚未听牌就把后手收益归零更接近“边打边看、保留做大方向、预留后手”的思路。该解释只成立于这个人工环境和受限收益模型；不能据此写成固定“遇到这些牌就弃4万”规则，也不能称为自然实际入口分岔。9 个自然根的最终选择仍全部不变。

教材 6-20B 的人工三张小墙反例，旧一次收入 0、新两次收入 27 的结构修补仍成立；指定双观察前缀的联合收入为 9。它证明遗漏后续改良会丢掉合法机会，原书真实墙未知，不能把 27 当作原局实战期望。

预先冻结的双前缀有效样本门槛仍为 96，概率筛选下限仍为 0.001。4 个失败根全部保留：自然 seed21920113、seat2、wall12 的最低有效样本 39.44；人工 6-19A/B/D 的 wall16 分别最低 93.77、90.26、73.39。旧诊断的 `case_id=null` 已在追加诊断中补回原始开发身份，没有增加独立来源。

进一步分离了样本支持和权重集中：这些根在最差双前缀下仍有 203–819 个支持该观察的粒子；若只作诊断、将同批计数假设的基础权重临时等化，对应有效支持为 181.81–688.12，均高于 96。真实重要性权重与观察似然相乘后却会集中到少数粒子。自然失败根中，仅一个粒子可占条件质量约 7.7%–12.6%，前五个占约 23.9%–29.0%。这表明当前提案的权重集中是主要问题；等化权重会改掉后验，只能用来定位原因，不能用来制造达标结果。

新增全图独立验收已经完成，开发稳定性仍未全通过，整体策略应用仍未完成。下一步应预先冻结通用提案改良、观察前缀条件重采样或新增粒子规模实验，并保持精确重要性修正及所有旧根、种子对照；同时补对家动作/退出、点炮/抢杠/呼叫转移成本、后续转向和终局查叫等范围。独立多来源概率校准、自然真实入口有效分歧以及完整对局到真实结算的晋级比较仍缺失。评分继续留在研究阶段，终端无需逐手完整终局模拟、无需本地每盘记录的边界保持。
