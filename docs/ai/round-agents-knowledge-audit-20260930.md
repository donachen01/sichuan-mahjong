# 新局内智能体：清一色计划与既有知识接入审计

本轮针对用户提出的三点检查，不是新增默认回归清单，也不以“代码中有类名”代替实际接入证据。

## 1. 清一色已经补进每家计划

`AgentPlan.FlushRoutes` 持续保存三个目标门的评估，包括不可用原因，不能仅报告当前主路线。每门包含：

- 是否符合缺门与副露约束；是否为其余三家都缺该门的单行道。
- 本家目标门暗手数量、还留多少异门。
- 依据公开未见副本，组成合法清一色胡牌结构至少还要取得多少张牌。
- 缩短上述距离的牌种、对应未见副本数、最近完成结构共同依赖的瓶颈牌。
- 在合法 13 张且清缺完成时，枚举“摸牌—合法舍牌”后距离不变而有效副本增加的改良；记录能否保持原有普通型听牌。

计算重用已有 `SichuanFlushStructureEngine`，包含普通清一色和合法清七对目标，不重新创造另一套牌形规则。14 张待舍及未清缺场景标记改良未评估，由原有正式弃牌候选后继计算处理，不能把空数组解读为没有发展空间。

距离单位明确是“距清一色胡牌还需取得的牌数”，不是普通型向听数。例：已听清一色，通常还需取得一张胡牌张，距离为 1，而普通向听为 0。副本数是未见供应上界，不是已知牌墙数量或完成概率。

新字段用于持续记录和复核；现有出牌决策中的清一色规划、单行道评估、普通胡退路继续运行。没有把新增结构明细再叠加成一份重复奖励，也不宣称本轮新建了多路线统一收益搜索。

## 2. 两门暗手与两门副露必须区分

| 情形 | 清一色目标 |
|---|---|
| 手里暂时还有两门，未副露 | 可保留；比较进张、现张、清色收益与普通胡退路 |
| 已碰/杠的牌全部在目标门，暗手还有另一门 | 可保留；异门暗手可以后续舍出 |
| 已经碰/杠出两个不同花色 | 不可达；副露不能拆回手中，胡牌也要算入它们 |
| 当前目标门已有异门副露，但另一个目标门与所有副露同色 | 应检查另一个合法目标，不能因此封死所有做大方向 |

本项目真实番型判定 `SichuanFanProjectionEngine.Project` 把暗手与所有副露合并后，只有一个花色才认定清一色。因此“单行道可以撤销两门既成副露”不符合现有规则。单行道改变未来供应与取舍，不改变已副露的不可逆性。

已跨两门副露时，仍可根据合法条件评估对子胡、带根、杠收益等其他做大机会；不能将这些收益贴成清一色。用户强调的“边打边看、保留普通听口并向大牌发展”适用于仍有合法发展路径的局面，不应变成强制拆听或无条件拒绝普通胡。

## 3. 原有学习内容是否进入新结构

核对了实际 Facade 分流、SeatAgent 的计算入口，以及出牌/反应/自家动作调用链；同时对照教材应用审计和图像课程能力归并。结论是：此前已进入正式算法的能力多数被复用，但不是所有学过的内容都已实现或验证。

| 学习内容 | 当前正式接入 | 仍需补全的边界 |
|---|---|---|
| K 神定缺；一门占优、三门均匀 | 本家定缺入口 → SichuanDingQueDecisionEngine → KScore；保存结果与确认。三连坎 +3，最低分严格执行 | 2.3/2.4只能在约定的最低分并列条件下参与，不得描述为可覆盖 K 分 |
| 洗脸先生后熟、同类先边后中 | 出牌最终选择中的 OpeningClearPolicy；并考虑早期集中花色观察 | 当前有阶段与威胁门槛，是有条件的进攻策略；不能称任何危险局面都机械执行口诀 |
| 清缺速度、手切/摸切与花色集中 | OpeningObservation → Evidence/Range；各智能体的对手档案保留事件来源 | 不能由过早清缺直接断定强牌；估计仍缺系统校准 |
| 普通型、七对距离及复合拆解 | 正式向听、精确听口、合法摸弃计算 | 最佳路线进张不等于已分别完整计算所有路线的收益；七对专属的改良/收益比较还不完整 |
| 同向听改良、孤张与搭子效率 | HandShapeEngine 调用 HandImprovementEngine；结果进入出牌评分 | 计算正确不保证最终取舍正确；部分形状奖励的优先级仍需牌例验证 |
| 抢和不等于抢碰 | 反应入口 → 统一后继；碰后正式首打、路线损失和结构比较仍生效 | 3.2遗留作者动作差异及一组花色轮换不一致没有被此次结构迁移自动修好 |
| 单行道、保留目标门与未来可出牌空间 | UnifiedDecisionEngine → SingleLaneEvaluator；QingYiSePlanner保留普通胡退路 | 供应、收益和竞争估价仍有近似，不是完整四家未来博弈 |
| 清一色距离、关键牌瓶颈 | 既有 FlushStructureEngine → 清色弃牌规划；本轮增加每家计划中的三目标门档案 | 普通、清色、七对的多路线后继与净收益尚未完全统一 |
| 保根、保护刻子、避免反复改意 | 持续战略、结构保护与候选比较由本家实例运行 | 不能把“高手习惯”一概写成硬规则；要允许合法性失效、收益下降和威胁变化推翻原计划 |
| 中后期危险与临时安全牌 | 公开证据、危险估计、防守时机及血战剩余人数仍在正式链路 | 对手真实听牌程度与危险概率没有充分校准；旧模块仍有局部阶段判断，需要进一步统一口径 |
| 贪番、胡与过、自摸例外 | 点炮反应和杠等收益比较已有；自摸入口仍选择胡 | 不能说已完整吸收书中所有自摸放飞/高风险贪番例外 |
| 56个图像课程的高手打法归并 | 已有相同机制可以提供支持，但课程卡本身只标知识采集完成 | 14个新能力候选、证据不足项不能统称已正式应用，不能据标题补造策略 |

迁移后的“独立计划”仍以现有路线权重、转换门槛和有限后继搜索为基础。它现在有明确的局内归属和证据记录，但还不是完整的长程条件规划器。后续应优先补普通/清色/七对后继的可比收益与阶段口径，而非继续堆叠习惯分数。

## 4. 审计发现的文档事实更正

设计文档此前沿用历史图解，误写 Visible18 包含本家暗手。当前桥接实际上是：Visible18 为公开牌，Remaining18 已扣公开牌与本家暗手；Codec 缺省剩余计算也是 `4 - visible - hand`。本轮改正文档，不改动已经正确的计算。清色新增评估直接使用 Remaining18，不再重复扣本家手牌。
