## 记录与确认边界

- 每条包含暗牌、副露、定缺、已出数量、明确未出牌、未知牌况、时间、危险/动作限制、认可结论、用户原话、后手理由、实现意图及历史错误。
- 未见副本上界不是实际牌墙数量。仅研究计算使用的假设单独保存，不升级为用户确认事实。
- 用户后续提供新条件或纠正时保留旧判断与撤回原因，新增或更新对应范围；不覆盖历史计算输出来制造一致性。
- 本轮仅整理判断与前提，没有修改游戏算法，没有创建固定回归清单。
