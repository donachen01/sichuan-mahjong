# 局内智能体不足项修正记录

本记录只描述本次实际改动和证据，不把路线机会指标解释为真实整局胜率。

## 已进入正式决策

1. 出牌、碰牌、杠牌共用 `SichuanStageEvaluator` 的前中后期口径。阶段考虑存墙、仍在场人数、自家预期摸牌次数及公开威胁；旧的局部墙数阈值已移除。局内计划也沿用同一阶段计算。
2. 清一色专项搜索的启动条件改为公开牌供应下的结构可达性：目标门不得是本家缺门，已副露的异门不能撤销，目标暗手数量、异门清理量、最近合法清色结构与剩余摸牌机会同时受约束。此前只按手牌张数套公式所得的“完成概率”不再负责启动搜索。
3. 每次合法弃牌之后，在相同的公开墙分布和四川规则下分别计算普通型、七对、各合法清一色目标的距胡牌张数、缩短距离的下一摸牌种、墙内预期副本和下一摸结构进展机会。该机会仅是同一时间尺度下的路线比较代理，采用最优特殊路线增量，最多给统一决策 0.45 的有界选项价值；不将可重叠的路线收益相加。已听牌仍使用原来的精确听口与结算计价，不额外给路线选项奖励。三家智能体的计划可逐家持有这些路线指标。
4. 清色规划中的“完成概率”改为**下一次本家摸牌直接完成清色胡牌**的机会。距离大于一张时该值为零，远期完成率明确留空；下次进展和成叫改用同一公开墙模型。番数按冻结的四川番上限及已经形成的根计基础值，避免旧公式凭张数推高“预计番”。
5. 反应短搜索的墙抽样以牌形确定起始花色。同一组公开牌只循环替换万、筒、条时，抽样仍对应同一结构，从而消除一例仅因编号顺序导致的过/碰翻转。
6. 尾盘零张牌墙时，精确牌形的近分裁决不再覆盖已计算的结算价值；同速同活进张时，成型对子保护先于一般经典牌形分排序。

## 验证口径

- `research/round_agents_20260930/shortcomings/flush_plan.json`：33 项针对路线合法性、真实清色距离、墙内进张、下一摸直接成胡及三路线智能体计划的聚焦检查。
- `research/round_agents_20260930/shortcomings/round_agents.json`：33 项三家局内实例、观察隔离及检查点检查。
- `research/round_agents_20260930/shortcomings/peng_facade.json`：18 个碰牌牌例的 54 个花色轮换运行，公开牌守恒和碰后正式首打均吻合，动作轮换不一致为零。
- `research/round_agents_20260930/shortcomings/runtime_flush.json` 与 `runtime_lifecycle.json`：真实 Godot/C# 桥接分别返回清色与新路线字段，并通过三家创建、恢复、重开和销毁的 20 项检查。开局尚在清缺阶段时，新路线后继数组为空；距离和清色计划仍单独提供。
- `research/round_agents_20260930/shortcomings/smoke_final.log`：现有 C# 全量 smoke 的本次结果。回归断言仅在旧前提已失效时更正：五张墙时允许为显著降风险少一张潜在进张；碰后投影是第二个状态，需要第二次推理构建；统一阶段原因采用“本家摸牌预算”。

## 尚未被证据证明的事

普通/清色/七对的有界机会代理不是完整血战到底结算净收益搜索，不能据此宣称三条路线的真实完成率、长期收益或胜率已校准。对手听牌后验已有自对局训练、留出局和另一批独立自对局的 Brier 检验（`evidence/ai_continuation_20260928/readiness_calibration.json`、`readiness_independent_calibration.json`），但这不能外推为人类对手校准；风险转换及单行道远期完成估计仍需带真实暗牌结果、覆盖开中尾盘的数据检验。教材 3.2 中部分作者选择与本项目构造牌例的差异，也不能因一组花色轮换修复就判为全部解决；需要先核对构造局面是否复现原文的公共信息和行动时序，再比较对局收益。本次未打包 iOS 或真机测试，不以桌面运行代替真机结论。
