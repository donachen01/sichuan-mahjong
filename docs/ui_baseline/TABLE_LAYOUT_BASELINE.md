# 牌桌布局基准 v17

本文件固化当前确认版麻将桌面布局。所有坐标以 `2048 x 1152` 为设计基准，实际界面按比例换算。

参考图：

- 骨架草图：`docs/ui_baseline/mockups/target_layout_zone_sketch_v17_discard_position_tune.png`
- 最终精修目标：用户提供的 `内江麻将界面修正对比.png`

本文档从本节起，统一以“最终精修目标图”为最高优先级。若旧骨架坐标说明与精修目标图冲突，以精修目标图为准。

## 总原则

- 桌面全屏铺满，不要棕色外框、网格线、底部横条。
- 初始界面左上角只显示 `+` 按钮；点开后才显示原悬浮的 `预 / 调 / 辅 / 明 / 退`。
- 房号、局数、时间不在主界面显示。
- AI 预设状态在右上 `下一局` 左侧显示，内容简化为两个字，例如 `地狱`、`老手`、`中级`。
- 右上角按钮显示 `下一局`。
- 四个玩家信息区贴四边角落，头像、昵称、积分、定缺、庄标识集中在玩家信息框内外。
- 四家都必须有独立动态牌区：手牌、碰杠、胡牌张分离显示，但整体动态伸缩。
- 公共出牌区按四家分区，围绕中心骰子/风位框排列，不混堆。
- 剩余牌数不单独显示，放进中心骰子/风位区域显示数字。
- 中心区最终不是“一个大空面板”，而是“上/左/中/右/下”五块清晰分区构成的十字结构。
- 对家动态牌区必须严格限制在顶部长条区域内，任何手牌、碰杠、胡牌张都不能溢出顶部动态区。
- 上家与下家动态牌区不得与对家动态区发生任何重叠，尤其是左右区域的上半段不能侵入顶部区域。

## 四家动态牌区

### 我方

底部动态牌区：`x 18-2030, y 938-1148`

| 子区 | 坐标 | 规则 |
| --- | --- | --- |
| 碰杠区 | `x 24-560, y 958-1144` | 左侧，最多约 5 张位 |
| 手牌区 | `x 568-1830, y 958-1144` | 中间，手牌最多 13 张 |
| 胡牌张 | `x 1840-2024, y 958-1144` | 右侧，单张 |

底部牌统一尺寸，手牌、碰杠、胡牌张大小一致。碰杠增加时，手牌减少，整体在底部动态伸缩。

精修版补充：

- 我方底部不是一整条连续白板，而是三个独立板块：
  - 左：碰杠板
  - 中：手牌长板
  - 右：胡牌单槽
- 右侧胡牌单槽必须独立成橙色单张位，不能混进中间手牌带。
- 我方信息区悬浮在底部动态区左上之外，不压碰杠板。

## 公共出牌区

### 对家出牌区

整体阶梯区域：

`(490,158) -> (1555,158) -> (1555,335) -> (1258,335) -> (1258,425) -> (790,425) -> (790,335) -> (490,335)`

排布规则：

- 第一排靠中心区域，`6` 张。
- 后续每排 `8` 张。
- v17 示例中三排坐标：
  - 第 1 排：`x 835, y 330`
  - 第 2 排：`x 760, y 250`
  - 第 3 排：`x 760, y 170`

精修版补充：

- 精修目标图中，对家公共出牌区最终呈现为“上两排更长、下排更短”的三排板式。
- 三排必须整体居中于顶部公共出牌板内部，不能贴左，也不能散落到整个中心大面板中。

### 我方出牌区

整体阶梯区域：

`(790,650) -> (1258,650) -> (1258,730) -> (1555,730) -> (1555,930) -> (490,930) -> (490,730) -> (790,730)`

排布规则：

- 第一排靠中心区域，`6` 张。
- 后续每排 `8` 张。
- 我方牌整体略向下，避免压中心线。
- v17 示例中三排坐标：
  - 第 1 排：`x 850, y 668`
  - 第 2 排：`x 760, y 756`
  - 第 3 排：`x 760, y 840`

精修版补充：

- 精修目标图中，我方公共出牌区最终呈现为“上排较短、下两排更长”的三排板式。
- 三排必须整体居中于底部公共出牌板内部，不得贴近骰子核心。

### 上家出牌区

区域：`x 490-790, y 335-760`

规则：

- 第一排靠中心侧，并在区域内居中。
- 第一排 `4` 张，后续每排 `6` 张。
- 牌按上家视角横置显示。
- 出牌必须被边框完整包住。

精修版补充：

- 顶部两张更短，底部收尾两张更短，中间主体为多排 3 张。
- 即便内部实现继续按列或按组计算，视觉结果必须与精修目标图一致。

### 下家出牌区

区域：`x 1258-1555, y 335-760`

规则：

- 第一排靠中心侧，并在区域内居中。
- 第一排 `4` 张，后续每排 `6` 张。
- 牌按下家视角横置显示。
- 出牌必须被边框完整包住。

精修版补充：

- 精修目标图中，下家公共出牌区也更接近“2 / 3 / 3 / 3 / 3 / 2”的阶梯排布效果。
- 视觉上要与上家左右对称，而不是简单复制上家坐标后再做镜像误差。

## 牌面方向

- 我方、对家公共出牌：正向竖牌。
- 上家、下家公共出牌：按各自玩家视角显示，当前草图用横置牌表达。
- 手牌、碰杠、胡牌张按玩家方向排列：我方/对家横排，左右两家竖排。

## ComfyUI 出图规则

v17 是布局坐标基准。正式视觉基准图使用本机 ComfyUI 生成，必须遵守本文件坐标和分区，不允许为了美观移动功能区。

精修目标图已经定义了最终视觉层级关系。后续无论是 Godot UI 实现还是 ComfyUI 出图，都必须满足：

- 顶部动态区、左右动态区、底部动态区必须是独立板块，而不是悬浮牌列。
- 中心区必须是十字板结构，而不是一整块大绿色台面。
- 胡牌张必须使用独立单槽表达，不能再被实现为“附在手牌尾部的一张”。
- 左右动态区不得与顶部动态区发生空间重叠。

ComfyUI 只负责：

- 高质感麻将桌布。
- 真实麻将牌质感。
- 头像/信息框质感。
- 中心骰子/风位视觉。
- 按钮与半透明面板质感。

ComfyUI 不负责重新设计布局。布局以 v17 坐标为准。

| 退出 / `TopExitButton` | 左上 `+` 展开后的 `退` | 退出牌局 |

| 定缺 / 规则提示 | 弹窗 | 保留现有逻辑；内江玩法无定缺时可隐藏按钮，只保留必要提示 |

| 待操作牌 + 倍数 | 操作按钮左侧 | 后续接入，主界面骨架先预留 |
| AI 出牌辅助详情 | 浮层面板 | 由 `辅` 开关控制，位置后续按不遮挡牌区调整 |

## 第一阶段实现边界

- 先在 Godot 中实现布局骨架。
- 只改 UI 位置、尺寸、层级、动态伸缩规则。
- 先不重做麻将牌图案、动画、特效。
- 先不改麻将判定逻辑。

## 验收点

- 左上只显示 `+`，不展开 5 个按钮。
- 右上显示 `下一局`。
- 对家牌区靠上，且动态区最多按 18 张规划。
- 我方底部牌区铺满底部，手牌最多 13 张。
- 上家/下家手牌、碰杠、胡牌张前后关系正确。
- 四家公共出牌区不重叠。
- 对家和我方出牌区能显示三排。
- 左右公共出牌区第一排靠中心侧并居中，牌完整包在边框内。
- 中心剩余牌数显示在骰子/风位区域内。
- 对家动态牌区任何牌张都不能出框。
- 上家与下家动态区上半部分不得与对家动态区重叠。
- 顶部、左右、底部公共出牌区必须形成精修目标图那种十字板式关系。
- 四家信息区必须采用头像卡片结构，而不是纯文本标签。
