# UI 基准落地计划

本文档只描述改造顺序，便于逐步评审。不要一次性全改。

> 2026-05-11 补充：主牌桌 3D 卡通轻奢精修的最新目标、完成度和版本闭环，以 `docs/ui_baseline/UX_REFINEMENT_TARGET_AND_PROGRESS.md` 为准。每次版本更新后必须更新该文档的完成度矩阵和未完成任务池。

## 阶段 1：牌桌清晰度优先

目标：先让手机上牌更大、更清楚，同时开始向启动页的圆润 3D 卡通质感靠拢。

建议改动：

- 将自家手牌基准从 `92x138` 提升到约 `104x156` 或 `108x162`。
- 给自家手牌强化 3D 厚度：暖白牌面、绿色侧边、底部软阴影、高光。
- 自家手牌区域高度从当前 `292` 提升到 `330-360`，减少上方说明卡占位。
- 将动作按钮改为右下浮动圆形/果冻厚按钮，不再放在小矩形 action panel 中。
- `胡` 主按钮直径 `144` 左右，`过/碰/杠` 直径 `112-128`。
- 中心常驻统计/提示卡收起，改为小按钮或临时提示。

优先文件：

- `scripts/ui/HandCanvas2D.gd`
- `scripts/game/MainSceneV2.gd`
- `scenes/table/MainSceneV2.tscn`

验收截图：

- 发牌后正常桌面
- 有胡/碰/杠/过按钮时
- 自家 14 张牌且最后摸牌有间隔时

## 阶段 2：玩家区和桌面布局

目标：让界面更像“启动页里的牌桌真正进入游戏后”的样子，同时保持参考图 1 的清晰度。

建议改动：

- 左右玩家 rail 从大面板改为贴边头像卡。
- 玩家头像卡采用圆润木牌/软卡片样式，可逐步替换为软萌 3D 卡通头像。
- 顶部玩家牌背横排更清楚，保留头像和分数。
- 中央桌面扩大，弃牌区和副露区不被统计卡压缩；桌面边框向启动页木框靠拢。
- 常用辅助按钮改为右侧竖排小圆按钮，使用木质/果冻质感。

优先文件：

- `scripts/ui/PlayerUI.gd`
- `scenes/ui/PlayerUI.tscn`
- `scripts/game/MainSceneV2.gd`

验收截图：

- 四家都有弃牌
- 左右玩家有碰/杠牌
- 有人已胡后继续血战

## 阶段 3：结算页重做

目标：采用参考图 2 的“大、清楚、结果先行”结构，但视觉改成启动页同源的木框 + 奶油黄 + 暖红橙金 3D 卡通结算面板。

建议改动：

- `SettlementPanel` 改为屏幕百分比布局，约 `82vw x 70vh`。
- 采用“左玩家列表 + 右结果详情”的大结构。
- 右侧顶部做暖红/橙金 3D 结果栏，显示：赢家/输家关系、牌型、番/分、得分。
- 手牌展示区改为奶油黄托盘/木框牌盘，牌面单行优先。
- 明细区从表格式小字改为大字号结算条。
- 底部按钮改为大号 3D 厚按钮：继续、返回桌面。

优先文件：

- `scenes/table/MainSceneV2.tscn`
- `scripts/game/MainSceneV2.gd`

验收截图：

- 自摸结算
- 点炮结算
- 杠上炮/抢杠胡/呼叫转移结算
- 多归龙七对 16 分结算

## 阶段 4：截图自动验收

目标：改 UI 后不再靠肉眼临时看一张图。

建议新增工具：

- `tools/capture_ui_baseline.gd`
- 输出目录：`artifacts/ui_baseline/YYYYMMDD_HHMM/`
- 固定分辨率：
  - `2048x1152`
  - `1920x1080`
  - `1365x768`

每次 UI 改动必须产出：

- `table_normal.png`
- `table_reaction_buttons.png`
- `settlement_self_draw.png`
- `settlement_discard_win.png`

## 讨论点

需要用户确认：

- 牌桌是否完全使用启动页的暖木房间背景，还是游戏中只保留木框牌桌 + 绿色绒布。
- 结算页红色结果区的比例：更像参考图 2 的大红面板，还是更像启动页标题的橙金牌匾。
- 头像是否使用真实图片/内置头像，还是继续文字方位牌。
- 是否隐藏当前的 AI 调参、助手、对手手牌等调试入口到二级菜单。
